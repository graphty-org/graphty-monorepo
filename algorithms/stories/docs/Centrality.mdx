# Centrality

Centrality scores rank the nodes of a graph by how important they are. Each measure has its own idea of importance: many edges (degree), lying between other nodes (betweenness), being near everything (closeness), or being linked to other important nodes (eigenvector, Katz, PageRank, HITS). Every function returns one score per node index.

```ts
import { betweennessCentrality } from "@graphty/algorithms";

const { scores } = betweennessCentrality(snapshot);
// scores[i] is the score of node index i
```

`snapshot` is a `GraphSnapshot` built with `GraphBuilder` from `@graphty/graph-format`; see
[Getting started](?path=/docs/introduction--getting-started).
