# Communities

Community detection and clustering split a graph into groups of nodes that are more tightly linked to each other than to the rest. Louvain, Leiden, label propagation and Girvan-Newman find the number of groups themselves; hierarchical, spectral and Markov clustering take or tune it; k-core decomposition finds the dense cores instead of a partition. A partition comes back as `labels`, one group number per node index, with `count` groups.

```ts
import { louvain } from "@graphty/algorithms";

const { labels, count, modularity } = louvain(snapshot);
// labels[i] is the community (0 to count - 1) of node index i
```

`snapshot` is a `GraphSnapshot` built with `GraphBuilder` from `@graphty/graph-format`; see
[Getting started](?path=/docs/introduction--getting-started).
