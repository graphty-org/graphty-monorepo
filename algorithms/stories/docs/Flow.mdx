# Flow

Flow algorithms treat edge weights as capacities. Maximum flow finds the most that can travel from a source to a sink of a directed network; the edges it saturates form a minimum cut between the two. Stoer-Wagner finds the minimum cut of an undirected graph with no source or sink given.

```ts
import { maxFlow } from "@graphty/algorithms";

// a directed snapshot; each edge's weight is its capacity
const { maxFlow: total, flow, cutEdges } = maxFlow(snapshot, { id: "s" }, { id: "t" });
// flow[e]: the flow on edge index e; cutEdges: the edges of a minimum cut
```

`snapshot` is a `GraphSnapshot` built with `GraphBuilder` from `@graphty/graph-format`; see
[Getting started](?path=/docs/introduction--getting-started).
