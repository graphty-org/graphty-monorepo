# Link prediction

Link prediction ranks the pairs of nodes that have no edge by how likely one is, from the neighbors they share. Common neighbors counts the shared neighbors; Adamic-Adar weights each shared neighbor by how few edges it has. Pass `uniquePairs: true` to list each pair once.

```ts
import { commonNeighborsPrediction } from "@graphty/algorithms";

const { sources, targets, scores } = commonNeighborsPrediction(snapshot, { topK: 5, uniquePairs: true });
// pair k is (sources[k], targets[k]), node indices, best first
```

`snapshot` is a `GraphSnapshot` built with `GraphBuilder` from `@graphty/graph-format`; see
[Getting started](?path=/docs/introduction--getting-started).
