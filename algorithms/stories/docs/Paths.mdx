# Paths

Traversals visit the nodes reachable from a start node in a fixed order: breadth-first visits the nearest first, depth-first follows one branch to its end. Shortest-path algorithms find the cheapest route by edge weight: Dijkstra for non-negative weights, Bellman-Ford when weights can be negative, A\* toward one goal with a heuristic, and Floyd-Warshall for every pair at once.

```ts
import { dijkstra } from "@graphty/algorithms";

const result = dijkstra(snapshot, snapshot.ids.requireIndex("a"));
const path = result.pathTo(snapshot.ids.requireIndex("b"));
// result.dist[i]: the distance to node index i; path: node indices from "a" to "b"
```

`snapshot` is a `GraphSnapshot` built with `GraphBuilder` from `@graphty/graph-format`; see
[Getting started](?path=/docs/introduction--getting-started).
