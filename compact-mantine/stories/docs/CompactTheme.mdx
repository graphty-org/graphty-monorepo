# The compact theme

`compactTheme` is a complete Mantine theme that draws Mantine's components the way Figma's
editor draws its own: 24px controls on an 11px Inter face, neutral greys, a 240px panel,
dark menus and tooltips in both colour schemes. It needs one line and no other setup -- the
Inter font, the design tokens and the shared styles are injected by the first themed component
to render.

```tsx
import "@mantine/core/styles.css";

import { MantineProvider } from "@mantine/core";
import { compactTheme } from "@graphty/compact-mantine";

<MantineProvider theme={compactTheme}>
    <App />
</MantineProvider>;
```

## Light and dark

Light and dark are Mantine's own colour scheme: `defaultColorScheme`, `forceColorScheme` and
`useMantineColorScheme` work as they always do, and one theme object serves both. Every colour
is a CSS custom property (`--cm-bg`, `--cm-text-secondary`, `--cm-bg-brand`, ...) written with
`light-dark()`, so it follows the `color-scheme` of whatever element uses it. Menus, listboxes,
tooltips and the toast render dark in both schemes, as Figma's do.

## The WCAG AA option

The default is exact Figma, and a few of Figma's own colours fall short of WCAG 2.2 AA:
secondary text on a field, placeholder text, the checkbox border, the focus ring on white, and
white text on the blue, red and green fills. Pass `highContrast: true` to move exactly those
tokens to the next darker colour in Figma's palette; nothing else changes, and dividers stay as
Figma draws them.

```tsx
import { createCompactTheme } from "@graphty/compact-mantine";

<MantineProvider theme={createCompactTheme({ highContrast: true })}>
    <App />
</MantineProvider>;
```

The toolbar's **Contrast** control switches every story between the two. The chosen option is
published as `theme.other.compact.highContrast`. One page renders one contrast mode: two
providers with different settings on the same page are not supported.

## What it sets

- **Type** -- Inter Variable, bundled (SIL Open Font License; the license ships in
  `dist/fonts/`). Body text 11/16 at weight 450 with 0.055px tracking; emphasis is weight
  (550, and 600 for top-level layer names), never size or colour.
- **`fontSizes` / `lineHeights`** -- xs 9/14, sm 11/16, md 13/22, lg 15/25, xl 24/32
- **`spacing`** -- xs 4px, sm 8px, md 8px, lg 12px, xl 16px (Figma's 4px grid)
- **`radius`** -- xs 2px, sm and md 5px, lg and xl 13px (menus, popovers, modals)
- **`shadows`** -- xs to xl are Figma's five elevations
- **`primaryColor`** -- `brand`, Figma's blue: #0d99ff filled, #007be5 links, #0768cf pressed
  (#0c8ce9 in dark)
- **`colors.dark`** -- a neutral ramp: #2c2c2c panels, #383838 fields, #444 hover
- **Focus** -- Figma's 1px #0d99ff ring on keyboard focus (inside fields, outside buttons).
  Mantine's own ring is switched off (`focusRing: "never"`).
- **Motion** -- menus, popovers, tooltips and modals open in one frame; only small state
  changes (a checkbox tick, a switch knob, a hover colour) animate, for 100ms.

Components default to `size="sm"`, a 24px control. Pass `size="md"` or `size="lg"` for larger.

## Server rendering and shadow roots

The stylesheet is injected into `document.head` on the first render. Without a DOM (server
rendering), put `compactGlobalCss()` in a `<style>` in your document head instead; pass
`{ highContrast: true }` to get the AA tokens without relying on the page attribute. The same
string works inside a shadow root.

## Making it your own

`compactTheme` is already merged with Mantine's default theme, so merge yours on top of it:

```tsx
import { createTheme, mergeMantineTheme } from "@mantine/core";
import { compactTheme } from "@graphty/compact-mantine";

const theme = mergeMantineTheme(compactTheme, createTheme({
    primaryColor: "teal",
}));
```

If you build your theme from several overrides instead, take `compactThemeOverride` (the same
as `createCompactTheme()`). It goes straight into `mergeThemeOverrides()`.

## A compact region inside a normal-sized app

`MantineProvider` nests, so an application can stay at its usual size and make one region
dense -- which is what a sidebar or an inspector usually wants.

```tsx
<MantineProvider>
    <TextInput label="Normal size" />

    <MantineProvider theme={compactTheme}>
        <aside style={{width: 240}}>
            <TextInput label="Compact" />
        </aside>
    </MantineProvider>
</MantineProvider>
```

## Colour and geometry for your own rows

Reach for `PANEL_INK` rather than a hex. It names one colour per role -- `VALUE` for primary
text, `CHROME` for secondary, `SURFACE` for a field, `SELECTED`, `HOVER`, `BORDER`, `ACCENT`,
`FOCUS`, `MENU`, and more -- and every entry is a `--cm-*` token, so it follows the colour
scheme and the contrast option without further work.

```tsx
import { PANEL_GRID, PANEL_INK } from "@graphty/compact-mantine";

<div style={{height: PANEL_GRID.ROW_PITCH, color: PANEL_INK.CHROME}}>Custom row</div>;
```

`PANEL_GRID` is the panel's pixel grid: `16 | 88 | 8 | 88 | 8 | 24 | 8` across a 240px panel,
32px rows, 24px controls. It is also published on the theme as `theme.other.panelGrid`.
