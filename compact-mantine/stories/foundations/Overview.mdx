# Foundations

What the theme sets before any component is drawn: the colors, the type, the spacing and the
panel grid, the shadows, the focus ring and motion, and the small drawings that stand in for
words. Every component in this package is built from these, and so is every Mantine component
once `compactTheme` is in your `MantineProvider`.

```tsx
import "@mantine/core/styles.css";

import { MantineProvider, Text } from "@mantine/core";
import { compactTheme, PANEL_GRID, PANEL_INK } from "@graphty/compact-mantine";

<MantineProvider theme={compactTheme}>
    {/* 11px Inter at weight 450, in the primary text color, on the 240px panel column */}
    <div style={{ width: PANEL_GRID.WIDTH }}>
        <Text size="sm" c={PANEL_INK.VALUE}>
            Node size
        </Text>
    </div>
</MantineProvider>;
```

  their names.
