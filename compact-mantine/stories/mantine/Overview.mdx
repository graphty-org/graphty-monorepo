# Themed Mantine

Mantine components that the compact theme restyles but this package does not wrap. You import
them from `@mantine/core` as usual, and their props are Mantine's: each page links to the
component's page on mantine.dev. The pages here show that they fit beside this package's own
components, in every state, in light and dark.

```tsx
import { Button, Checkbox, MantineProvider, TextInput } from "@mantine/core";
import { compactTheme } from "@graphty/compact-mantine";

<MantineProvider theme={compactTheme}>
    <TextInput label="Project name" />
    <Checkbox label="Show labels" />
    <Button>Save</Button>
</MantineProvider>;
```
