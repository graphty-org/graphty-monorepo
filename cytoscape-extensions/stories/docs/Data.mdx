# Data

Four core methods get graphs in and out of Cytoscape. Each returns a promise, because its code loads the first time
it is called:

```js
async function load(cy) {
    // a seeded graph: the same options and seed give the same graph on every platform
    await cy.graphtyGenerate("planted-partition", { groups: 4, groupSize: 25, pIn: 0.3, pOut: 0.01, seed: 1 });
    // or a sample dataset, downloaded when it is asked for
    await cy.graphtyDataset("karate");
    // or a file, in any of thirteen formats ("auto" detects the format)
    const { format } = await cy.graphtyImport(text);
    // and back out
    const graphml = await cy.graphtyExport("graphml");
}
```
