# Research notes

The evidence the framework documents cite. It is not authority: where a note and a framework
document disagree, the framework document wins. `archive/` keeps the long forms that were split,
as the record.

| Research note | What it contains |
|---|---|
| `research/figma.md` | Figma's principles, object model, vocabulary and surfaces, with a verdict on what transfers |
| `research/graph-analysis.md`, `research/graph-tools.md` | the visualization and network-science literature; how other graph tools model the same concepts |
| `research/design-method.md` | the methods the documents follow and the review checklist |
| `research/graphty-today.md` | what graphty-element publishes today, what exists only in the app, measured behavior |
| `research/color-checks.md`, `research/scale-measurements.md` | contrast and palette measurements; size, stability and quotient measurements |
| `research/study-schedule.md` | every planned study, its bars, tasks and answer keys, and the consistency check's last result |
| `research/principles-worked-conflicts.md`, `research/interaction-patterns-rejected.md` | the budget checks behind the conflict ledger; the rejected interaction alternatives |
| `research/document-set-trials.md`, `research/key-insights.md`, `research/sets-in-graphty-today.md` | the routing trials behind this set; a digest of the research; sets before the 2.6.0 release |
| `research/study-schedule.md`, `research/last-check.txt` | the studies; the last run of the document lint, written by the lint |
| `research/model-task-walk.md`, `research/interface-checks.md` | every top task written in the model's operations; desk recounts and the inference check over real files |
