# The top tasks written in the model

Evidence for `conceptual-model.md`: each top task (numbers are `top-tasks.md`'s) written as the
model's operations (`conceptual-model.md` 7.1). A task that cannot be written this way is a gap in
the model, not in this note.


Each step is an operation of 7.1; numbers are `top-tasks.md`'s.

- **Load**: Load -> data version, import report -> overview recipe and floor.
- **Start from a recipe**: Apply recipe -> bind slots, weight confirmed -> unbound off -> runs.

1. **Characterize**: overview recipe -> Statistics of the filtered graph.
2. **Rank**: run a metric -> result attribute -> style layer. Then Filter out a component: the run
   shows a different scope, not out of date; Re-run adds a run, the layer repaints, the earlier run
   is the baseline.
3. **Communities**: partition run -> items -> Profile groups -> offer -> Create set.
4. **Find and explore**: Find -> selection -> Filter to (a step) -> Select neighbors
   (the selection grows, no undo step) -> Filter to neighbors (the step grows, one undo step).
5. **Note**: Add note on a primary object, citing runs.
6. **Filter, then characterize**: Filter to or Filter out (a step) -> Statistics of the filtered graph.
7. **Layout**: Run layout over the layout settings' scope (the filtered graph by default, 4.4) or
   a set -> live positions; Pin.
8. **Color or size by a value**: bind a channel of a new style layer to an attribute; the level
   picks the scale.
9. **Sets**: Create set from the selection or an item; Union, Intersect, Subtract or Exclude -> a
   rule set naming its operands; Create set freezes it.
10. **Compare**: Compare with... on two operands -> Save comparison -> a comparison run.
11. **Shortest path**: search run with its stated scope -> found path -> Create path.
12. **Reuse**: Replace data (new data under the analysis) or Apply recipe (an analysis over the data).

- **Export**: a figure from a saved view, a ranked table, the project file.
