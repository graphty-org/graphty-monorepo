Mock kit: the object-first graphty chrome

Theme

Every piece of chrome the mocks are built from, in every state, in light and dark. Measurements come from the Figma study in design/ui/figma/ (components.md and tokens/tokens.json). Each item is labelled with its size and the class that draws it. States that need a pointer (hover, pressed, focus) are shown with a state class (.is-hover, .is-pressed, .is-focus) so they render without one. The stylesheet is kit.css; the icon sprite at the top of this page is copied into each mock. No external fonts: Inter if installed, otherwise the system UI font.
