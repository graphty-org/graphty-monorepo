Refined B, version 3: answers to your third review

Each answer says what changed and where to click. "Your decision" means you decided it; everything else is a studio decision, reversible with an edit. Items needing graphty-element are drawn disabled; "Hide design notes" hides their marks, as the user-test build will.

The ten questions

1. What do the numbers in "Line 5" and "Arrow head 4" mean?

They counted the properties the row sets in that section, and nothing on screen said so. Every property count is gone; a Nodes | Edges side that sets something gets a small dot. A bare number now only ever counts members or results.

See Edges side of a groupEverything, Edges

2. Empty values: "+" or popovers?

Both, each with one job, and no accordions in anything editable. A row lists only what it sets, because graphty-element has no "unset" value to draw. "+" in a section header adds a property; clicking a value opens one Figma-style popover holding everything about it (opacity in Color, size and caption in each arrow end).

See + menuColor popoverArrowsBinding popoverLabel style

3. Everything looks different from "For the report"

It was a separate code path, now deleted: Everything uses the same Style tab as every row, starting from graphty-element's real defaults, and is editable today (only its eye waits on the element). "For the report" is a folder, which paints nothing itself; its inspector says so and lists its rows.

See Side by sideEverything, one line changedThe folder

4. Why are the legend and camera controls on the canvas?

No good reason, so they left. The toolbar now holds every command that acts on the whole canvas: Analyze | Layout, View, Legend | Quick actions. View folds the camera, saved views, 2D/3D, VR and AR into one flyout; Legend is a toggle.

See ToolbarView flyoutLegend offLayout paused

5. No text on the toolbar; tooltips after a delay (your decision)

Done, with one tooltip for every icon-only control: name and key after 500 ms, at once on keyboard focus or when moving to a neighbor, Esc dismisses. The selection bar follows the same rule.

See Tooltip on hoverOn keyboard focusSelection bar

6. Is the Data sidebar doing too much?

Yes. It keeps Sources, Filters and Attributes, one line per row, "+" in each header. Versions moved to Version history and "Sent and saved" to Export's Recent exports. How a file is read changes in the load dialog; how a column is interpreted changes in its inspector.

See Data placeA sourceAn attributeRecent exports

7. How much of Tableau to copy

A graph file already is a Tableau relationship (edge ends point at node ids), so there is little to model. Copied: File, URL and Paste as sources, roles chosen under sample columns, typed fields, filters as sentences, a lost-fields warning on refresh. Later: one "add columns by key" join, which needs graphty-element. Skipped: drawn relationships, unions, dimensions and measures, blending, extracts.

See Load dialogReplace, lost fieldsFilters

8. Labels from a field, a note, or the number of notes

A field works today with the ordinary bind gesture: Label "+" adds Text already bound to the Name attribute, and the bind list offers every attribute and run result; attributes also get Label by. Note text and note count are designed but disabled, because graphty-element has no notes a binding can read.

See Label bound to NameLabel from data: fields, results, notesLabel by

9. Notes on edges

Yes. A note can be about a node, an edge, any row, a filter step or the graph, with one gesture (Add note, N). Edges cannot be picked on the canvas yet, so they are noted from the table or a path; one sample note is about Javert -- Valjean.

See A note about an edgeThe edge's inspector

10. "Why this look" collapsible (your decision)

Done with the shared collapsible section, remembered, with a one-line summary when closed. It lists only rows that win a property, and each token opens the Style tab's own popover, writing to Overrides.

See OpenClosedAfter an edit

The primary focus: ten simplifications that matter most

Most findings were a second way to do an existing job, so the work is mostly deletion: about 60 controls, states and screens removed.

  1. One tooltip for every icon-only control; the toolbar and selection bar carry no text. TooltipSelection bar
  2. The canvas carries no controls: View, Layout and Legend moved into the toolbar. ToolbarView
  3. Three surfaces, one job each: dark menus choose, light popovers edit and apply live (no Done or Cancel), modals take over. PopoverMenu
  4. A style row lists only what it sets; "+" in the section header adds; no counts, no accordions. Style tab+ menu
  5. Everything, folders and rows share one Style tab and one inspector layout. Side by sideFolder
  6. Create first, then name in place; rename is double-click or F2 everywhere; delete acts at once with Undo. RenameUndo notice
  7. Paths come from one Path popover; the six-state pick mode is gone. Path popover
  8. The Data place is three one-line lists; one load dialog serves every door, with roles chosen under the sample columns. Data placeLoad dialog
  9. Analyze shows only the essentials: Weight, one key option, Scope only with a selection. Analyze
  10. Export is five outputs in one dialog; Settings is six sections; one empty state and one state card everywhere. ExportSettingsEmptyState card
