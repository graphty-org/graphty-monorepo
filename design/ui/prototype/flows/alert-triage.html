Select neighbors, chosen from the menu

Nine selected, the chip still reads Full graph: only the selection changed. The main press of Neighbors filters, so this is a deliberate choice. Filter to on the selection makes the step (undo label "Filter to 9 nodes").

Delete step with nothing kept

The step's line reads "Nothing kept or exported from this step" in caution ink. Delete still takes no confirmation; the notice offers Undo.

Usage data turned on

Had Nadia said yes at first use, graphty sends which steps she takes and how long they take, errors, and a screen replay with every account id, amount, label and file content masked, to graphty's author only. No transfer ever leaves. Preferences > Usage data turns it off.

Export canceled or blocked

Cancel writes nothing. If the browser blocks the download, the dialog says "Could not export 2 files: the browser blocked the download" with Export; the kept-and-exported line does not change.
