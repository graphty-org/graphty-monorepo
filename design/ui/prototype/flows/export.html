Design gallery

Export a figure, a recipe or an evidence file

Everything that leaves graphty leaves through one Export dialog. It has three ways in: Export... in the menu under the project name, Export... in the Data panel's header, and Export table... in the table dock, which opens the same dialog with the table chosen. Ctrl+Shift+E opens it from anywhere. This page follows one analysis from start to finish: Maren, a postdoc, turns this week's qPCR results into a network figure a reviewer can read in black and white -- which genes went up, which went down, and which barely moved -- then writes the table behind it for the supplement. The other outputs of the same dialog (the setup without data, the findings report, the project) are drawn on the same project below. Shapes with a drawn screen state link to it.

The project

DataHuman protein interactions, ppi-core-300.graphml: 300 proteins and 1,262 interactions, undirected, weighted by confidence. The project is called Stress response study.
The signed columnThis week's qPCR file, qpcr-hits-2026-09.csv, added as a table in the Data panel and joined by gene symbol: 84 of its 96 rows matched a protein. Its log2FC runs -2.41 to 2.98: 48 genes went down under stress and 36 went up. The other proteins have no value and are drawn as small gray dots.
The filter stepFilter to confidence >= 0.7 keeps 1,059 of the 1,262 interactions and every protein. The figure and the table are both written over this filtered graph, so they describe the same network.
What she needsA figure for a journal that prints in gray, from which a reader can tell which genes went up and which went down without the color, with the strongest genes named, a legend and a methods paragraph; and the interactions behind it as a CSV her reviewer can open in R or Excel.

What the Print look draws on a signed layer, and what the gray check tests

A signed column needs two facts on paper: how far each value is from 0, and on which side. Darkness alone cannot carry both, so the Print look gives each fact its own channel. Darkness is the distance from 0, the same on both sides, so the largest decrease prints as dark as the largest increase. The sign is a shape: a triangle pointing up above 0, pointing down below it, and a circle for values inside the band the analyst stated as no change (here -0.58 to +0.58, a 1.5-fold change). Shape survives gray print and every kind of color vision, so Print is one look for both needs. When a shape layer sits higher in the stack and already owns the marks' shape, the sign moves to fill: filled above 0, outline only below.

The check is graphty-element's and the dialog only shows its verdict. It compares every pair of bins on opposite sides of the midpoint, not just the two ends: the round before, a check of the ends passed a ramp that printed the largest decreases palest. Two marks on opposite sides stay apart when their shapes differ or their grays differ by more than the threshold; two circles inside the no-change band are meant to match. The pass verdict gives the counts on each side so the reader can reconcile them with the legend. With no band stated, there are no circles, and the legend says "No band around 0 set".

The walk, step by step

Maren's steps through the figure and the table, with what she sees at each one.

0Usage data: off

The first time graphty opened, before any graph, it asked once: "Your data is yours, but please help us. We will never see the data you analyze. With your yes, graphty records how you use the app, so we can make it easier to use. Only graphty's author and his Claude Code sessions will ever use it." Maren chose Not now, so usage data stays off, graphty does not ask again and nothing about this export is sent. Had she said yes, the export would be recorded only as "an export" and when it happened: never the file, its rows or its name, and every node name, value and label masked. Preferences > Usage data changes the choice. Where your data goes.

→

1Color by log2FC

On Attributes, with nothing selected, she picks Style by this, then Color, on log2FC. The column holds negative and positive numbers, so the new layer "log2FC color" diverges at 0 without being asked: red below, blue above, and a legend reading 48 below 0, 36 above. In the layer's midpoint row she types 0.58 into No change within, her lab's 1.5-fold cut-off. The layer, band included, is one undo entry. See the layer.

→

2Open Export

From the menu under the project name she picks Export... (the Data panel's header has the same button, and Ctrl+Shift+E opens it from anywhere). The dialog opens on the filter chip's scope, Filtered graph, with Figure (.svg) and Methods text checked, a white ground, and Look: Screen. See it.

→

3The check names the problem

Under the preview: "Values just above and below 0 print as the same gray", with Use Print look beside it. On the shipped red-to-blue palette the palest red and the palest blue both print as the same light gray, so on paper a small decrease cannot be told from a small increase. See it.

→

4Use Print look

The preview is redrawn as the file will be, with the same file in gray beside it. Darker means further from 0 on both sides, so GSK3B, the largest decrease, prints nearly as dark as PSMA2, the largest increase. Triangles point up or down; genes inside the band are circles. The ten strongest genes are named. The check now reads "Increases and decreases stay apart in gray (48 below 0, 36 above)", and the line beside Look says "File is written with: Print look". The canvas keeps its own look. See the figure.

→

5Export 2 files

stress-response-study_figure_2026-09.svg and stress-response-study_figure_2026-09-methods.txt go to the browser's Downloads; the names end in the month of the qPCR data they were made from. The dialog closes, a notice names both files, the Data panel's Sent and saved lists them with the data they were made from ("From the data loaded 2026-09-22"), and focus returns to where she opened the dialog. See it.

→

6Open the file, read it without color

She opens the SVG from Downloads and prints it in gray. It is the preview she approved: the triangles and circles, "Print look" as the legend's first line, the no-change band stated, the caption "Filtered graph: 1,059 of 1,262 interactions", the names as real text. Which genes went up? The ones whose triangles point up.

→

7Export the table behind it

In the table dock's Edges tab the scope line reads Filtered graph, 1,059 of 1,262 rows. Export table... opens the same Export dialog with Table (.csv) chosen: "Rows: 1,059 of 1,262, filtered", the file names, and its methods file, which is always written and cannot be unticked. Had she ticked Table (.csv) in step 2, the same row would have been written with the figure. See it.

→

8Open the CSV

In R, the CSV has 1,059 rows, as the dialog said, and no comment lines to trip the reader. stress-response-study_edges_2026-09-methods.txt names the scope and its filter step, the load choices, the weight's meaning and the graphty-element version, ready for the supplement.

Errors, cancellation and other graphs

Cancel

Cancel, Esc or the close button: nothing is written, no notice is shown, and focus returns to what opened the dialog -- the menu's owner, the Data panel's Export..., or Export table....

Keep the Screen look

For a journal that prints in color she may leave Look on Screen. The file is written in color, as the preview shows; the check's line stays in the dialog as a fact, never as a block.

A shape layer sits higher

Had a layer above hers set shape by module, the Print look would not take shape away from it: the sign moves to fill, filled above 0 and outline only below, marks inside the band keep their shape in the lightest gray with a dashed outline, and the legend says so. The check reads the same.

No band stated

Without a No change within value, the Print look draws no circles: every gene is a triangle, and the legend's line reads "No band around 0 set". The check still runs on every pair of bins.

The save failed

"Could not export ...: the browser blocked the download", in the dialog, announced at once, with Export. Every choice is kept. See it.

On a graph drawn as density, or too big to draw

Not on this project. On a graph drawn partly as density, the dialog and the caption both state how many were drawn one by one; past the drawing limit there is no picture, so each figure row is disabled with its reason and the table row stays. Density, too big.

On a case file: ranks, the open filter step, and next month's data

The same dialog on a money-laundering case: Sarah, a bank investigator, has March's transfers (transfers-2026-03.csv, 3,000 accounts) and a filter step, "in Mule ring suspects", holding the 14 accounts she thinks form a ring. The case system wants the ring as rows, ranked by PageRank, and a month later wants the same file on April's data.

1Export with the filter step open

With the step open she presses Ctrl+Shift+E. The dialog starts with that step's transfers: Table (.csv) on the Edges tab, the 28 transfers with both ends among its accounts. A line under the scope says why, "A filter step is open, so the export starts with its transfers", and Nodes is one click away. The file would be case-acc-233575_transfers_2026-03.csv. See it.

→

2Nodes: the ranked accounts

She picks Nodes: "14 of 3,000 rows, filtered". PageRank's rank is written as a whole number, and a separate Tie column says how many other accounts share the value, so both columns stay numeric in Excel and pandas. Accounts with the same value share a rank. A measure computed on a sample would write Rank low and Rank high in place of the two. The preview's last columns:

id,...,"PageRank rank (1 = highest, of 3,000)","PageRank tie (other accounts with the same value)"
ACC-753261,...,202,1
ACC-739987,...,235,0
ACC-350110,...,266,2

See it.

→

3Export 2 files

case-acc-233575_ring-pagerank_2026-03.csv and case-acc-233575_ring-pagerank_2026-03-methods.txt: every file name ends in the month of the data it was made from. Sent and saved lists the export with "Made from March 2026 data". See it.

→

4A month later: Export again, on April data

April's transfers are added as a new version, and the Data panel lists both. Under the March export in Sent and saved, a labeled button reads "Export again, on April data". It opens the dialog with the March file's settings run on April: the same step and columns, a line naming the old file and the new data, and ranks of 3,093 accounts. See it.

→

5A new file; March's is kept

case-acc-233575_ring-pagerank_2026-04.csv is written beside its methods file, which says it was made again from the March file's settings on April data. The March file is not touched, and Sent and saved lists the April export as "Made from April 2026 data". See it.

The other outputs of the same dialog

The same Export dialog, on the same project and scope, writes three more kinds, plus Image (.png) for slides. Where scripting the same export would start is marked, but it goes nowhere yet.

Share the setup, without data

For a partner lab: ticking it turns off and disables every kind that would carry the proteins, and the preview first says no data is inside. What travels: the filter step, the log2FC color layer with its no-change band, and the Print look; log2FC is marked for the recipient to supply from their own table, so it is never bound to a column that came with someone else's network. See it.

Findings report (.html) waits on graphty-element

One self-contained HTML file: the boundary first (1,059 of 1,262 interactions), then the saved views as pages with their notes and each note's author, then the methods. Figures are embedded, text is real text, it opens offline in any browser and prints to PDF. See it on another case.

Project

The whole analysis with its data, for a colleague who will keep working on it. It has no trust check: it is the analysis itself, not a claim about it.

Starting from a selection

With a set selected, TP53 neighbors for example, Export... opens the same dialog with Scope: the selection. There is no second export dialog: the same Look, check and preview apply to every figure.

Scripting the same export proposed

There is no scripting control in the dialog. Once graphty-element publishes calls that write these files, the methods text ends with one line naming their documentation page, and Help links to the same page; the shape is proposed in framework-changes.md.

ScaleThe same route at every size. A figure over the density boundary is written reduced and says so; past the drawing limit its row is disabled with its reason.

RecordAn export changes nothing in the project and has no undo entry; the Look chosen in the dialog applies to the file only. Each file written is listed in Data, Sent and saved. Coloring by log2FC, with its band, is the one step with an undo entry.
Desk countThe figure: 1 step to color (Style by this, Color) and 1 field for the band, then 3 steps (Export...; Use Print look; Export 2 files). The table: 1 travel (the Edges tab), 2 steps (Export table...; Export 2 files). Recipe: 2 steps (Export...; check Share the setup, without data) and Export, plus its name.
First failureA figure that goes to print with up and down in the same gray, or with the largest decreases printed palest, or without its legend or scope. Shape for the sign and a check of every pair of bins exist to prevent it.
Where the analyst may stallWill the reviewer see what I see? The In gray pane beside the preview answers on sight, and the check says in words which side each count is on.
KeyboardCtrl+Shift+E opens Export anywhere; Export... and Export table... are also in Quick actions. In the dialog, Tab moves through Scope, Look, the check line's Use Print look, each row's checkbox then its settings, Cancel, Export; Space toggles a row; Enter on Export commits; Esc cancels; focus returns to what opened it. The check's verdict is announced politely when it changes. No pointer-only step.
Re-entryWhere it started: the menu's owner, the Data panel, the same table tab, or the same selection.
