# Milestone 8: the seventh user study, the first on the clickable skeleton

Round 7 put 16 simulated personas through the clickable refined B skeleton, not still mocks. It met none of its four bars. Much of the failure is the skeleton: 18 of 61 tasks (67 sessions) could not reach the screen they tested, and 29 more hit a skeleton defect the graders say drove the rating. On the 14 tasks with no such defect, 91% succeeded at mean ease 4.86 of 7.

- Tree test: 98% correct, 63% direct; 9 of 16 tasks reach 70% direct. Picture for slides fell to 19% (13 of 16 opened the main menu first; 100% in round 6, with a File menu). A colleague's style file 13%, the 40-appearances weight 6%, a different arrangement 6%, select by a typed rule 6%, two-line labels 31%, rerun on April's file 63%.
- First click: 95%; every prompt at 70% or more. No one clicked the project name for a colleague's file.
- Sessions: 280 over 61 tasks, 66% success or success with difficulty, mean ease 3.54 (bar 5.5). 11 of 21 top and new tasks reach 80%; sets (0%), shortest path (46%) and color or size by a value (60%) fail on design.

Three severity-4 problems are open:

- You cannot add another month's rows to a loaded table: "Add data to this graph" opens a screen headed "Open as a new graph", and a matching file turns Load off.
- Select where is found from none of the places people looked.
- An exported picture drops the legend, with no switch to keep it.

The findings file lists 33 design findings, each with a direction, and separately the skeleton defects to fix before round 8 can measure the design. Studio decision, reversible: Export stays under the project name as you asked, and the main menu also gets the file commands, since 15 of 16 looked there.
