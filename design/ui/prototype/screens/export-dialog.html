Export dialog

Everything that leaves graphty is written by one Export dialog. There are three ways to open it: Export... in the project-name menu, the Export... button in the Data panel's header, and Export table... in the table, which opens it with Table already chosen. Ctrl+Shift+E opens it from anywhere. The dialog lists what can be written, each row named with its file type -- Figure (.svg), Image (.png), Table (.csv), Findings report (.html) -- and previews the checked row exactly as it will be written. A figure is previewed at its print size on a white ground, with its legend, the footer that says how the numbers were computed, and the text at 8 pt; in the Print look the preview shows the file beside the same file printed in gray. Every file that carries data is written with a methods file beside it.

Shown on Maren's stress-response study (300 proteins, colored by log2 fold change and sized by degree), on a bank's mule-ring case, and on a lab's shared setup. The route with its branches is the export flow.

1. Three ways in

Maren's project at rest, with the Data panel open and the table dock showing. The Data panel's header holds Export..., and the table dock holds Export table.... There is no Export button in the top right. Below, the third way in: the project-name menu, where Export... sits with its shortcut, Ctrl+Shift+E. All three open the same dialog.

1b. The project-name menu

The same project with the menu under the project's name open. Export... here, the Data panel's Export... and Ctrl+Shift+E all open the dialog with the current view's figure chosen.

2. A figure, with its legend and methods text

Opened from the menu. Figure (.svg) is checked and selected, and its settings open under it: which view, the width (174 mm, a two-column journal figure), a white background, and the labels, here the top 10 by the layer's own value, the size of the change. Two of the ten would overlap, so they are hidden, and the dialog says so with the list one click away. The preview is the file at print size: the legend beside the drawing, and under it the footer that says degree is exact and not normalized and that no weight was used. Look, for this file only, reads Screen, with one line saying what it does; under the preview the dialog says values near 0 would print as the same gray, with Use Print look beside it. Click Print to switch the preview and the file together.

3. The same figure in the Print look

After Use Print look. The preview now shows two things side by side: the file as it will be written, and the same file as a gray printer will print it. In Print, shape carries the sign (a triangle up for every value above 0, down for every value below) and darkness carries the size of the change in four gray steps, the same steps on both sides, so the largest decreases print as dark as the largest increases. Nothing is grouped as "no change": the counts are the Screen legend's, 148 below 0 and 152 above. The line under Look says what Print does to categories, none of which print alike, and the check prints the value each gray step stands for. The hidden-label list is open: MRE11 and RPL17. Each row selects its node, and the inspector's Show label anyway puts that label in the figure.

4. A table, from the table's Export table...

Sarah needs the mule ring's accounts as rows for the case system. In the table dock, filtered to the ring, she clicks Export table.... The same dialog opens with Table (.csv) checked and selected. It states the rows first, "14 of 3,000 rows, filtered", names the filter step, and previews the file's first lines with the file's own ids. The methods file beside it is always written, whichever way the dialog was opened.

5. Share the setup, without data

Maren Holt shares the lab's expression overlay with a partner lab. She checks Recipe. Every row that would carry her data turns off and is disabled, with one line saying why. The first thing the preview says is that no data is inside; then what travels (each run with its settings, the layout as its method and seed, the full text of a note that travels), what the recipient supplies, and what is not included.

6. The evidence file

Sarah refers the case. Findings report (.html), scoped to the filter step, is the case's evidence file: one HTML file that opens offline and prints to PDF from the browser. The boundary and its 14 accounts come first, then the saved views as pages with their notes, then the methods.

7. Written

After state 3. The dialog closes and focus returns to where it was opened from, here the project name. A toast names both files and the look. The Data panel's Sent and saved list gains the export at its top, so "what left this project, and when" has an answer. An export changes nothing in the project and has no undo entry.

8. The first release

State 2 as the first release draws it: Graph file and Findings report are absent until graphty-element can write them. Figure (.svg) and Image (.png) are there from the start. Nothing is shown disabled for a format that does not exist yet.
