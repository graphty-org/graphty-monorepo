Round 6 study plan

Round 6 measures two decisions round 5 reversed: runs move from the right panel to their own place on the rail, and Ctrl+Z brings back a cleared selection. Each is tested so the before and after can be compared cleanly: one change per arm, each arm in its own session, and the task wording kept exactly as it was. Round 5's lead for the rail place was partly inferred from answers people gave to both designs in one sitting, so it is measured again here without that shortcut.

The round's files go in study/round-6/: tree-test.md and its answers, first-click/, sessions/, focus-groups/ and insights.md.

Nothing starts until the kit gate passes. No tree test, first click or session runs until node kit/check.mjs --all reports no problem and node kit/prove-gate.mjs shows every rule still failing on its planted violation. A failed gate stops the whole round, not only the tasks it touches. In round 5 the decided design was not yet drawn, and 7 of the 18 repeated tasks measured the old mocks instead.

What each arm looks like

Tree test: where runs live

  • Main arm: the tree with Results on the rail, exactly as drawn above.
  • Label variant, tasks 1 to 4 only: the same tree with the rail place named "Runs" instead of "Results". Every other branch is word for word the same. These four tasks are the ones that decide where runs live: start a second ranking, see how one node scored, find how a calculation was set up, and read every score highest first.
  • Separate sessions: all 16 personas take each arm as its own session with no memory of the other. Half see the main arm first. Nobody answers both arms in one sitting, and no answer in one arm is filled in from the other; a session that does either is run again.
  • Which label wins (a studio decision, frozen before the round): "Runs" replaces "Results" only if it earns more than 4 extra direct successes over tasks 1 to 4 (of 64), the same margin round 5 used. Otherwise the label stays "Results".
  • Task 12, how the biggest group differs from the rest: the group's or set's own panel now counts as correct, and as direct when reached without going back. In round 5 14 of 16 people went there first, and the design now puts Compare with the rest on that panel.
  • Task 7 keeps its wording ("A colleague sent you a file of the colors and sizes their team always uses"), so the change to the Style stack's "+" is measured against the same question.
  • The other tasks and the pass bars (70% correct and 55% direct per task) are unchanged.

First click

  • Prompts 5, 8, 10 and 13 keep their wording: get back a cleared selection, bring in next month's file, find the cheapest route where a bigger transfer costs more, and bring in the lab's colors-and-sizes file.
  • Prompt 5 is shown once in each undo arm, in separate sessions. Ctrl+Z counts as correct only in the arm where it restores the selection.
  • Every still screen is shot again from the current mocks after the gate passes, so no participant sees an older drawing.

Think-aloud sessions

  • Undo: the get-back task keeps its wording ("After your last few actions the numbers changed in a way you did not expect. Get back to where you were.") and runs in both undo arms, each persona taking each arm in its own session, half in each order.
  • Money in against money out runs only on screens that show weighted degree (run and read, the table). If the gate finds a money screen without it, the task does not run, rather than running and being thrown out afterwards.
  • A figure a reviewer can read runs with Jordan, the marketing network analyst. In round 5 that session returned nothing and was dropped; this time a session that returns no transcript is run again, never left out.
  • Every other task from round 5 repeats as it was, so each change shows as a difference between rounds.

Every finding says the participants are simulated

Each table, chart and summary in the round says, on the same page and next to its numbers, that the participants are simulated from the persona files. A failed task is a strong signal; a passed one is a weak signal until real people confirm it.

What stays as it is

These worked in round 5 and are not reopened:

  • One File list in the main menu and the project-name menu: a picture for the paper and next month's file were both found directly by all 16.
  • Data > Sent and saved and the line under the project name for "has anything left this computer".
  • Taking out one filter step with its own delete on the filter chip.
  • Changing a color from the legend.
  • The method: 16 personas, scoring rules frozen before any answer is read, wrong or indirect picks counted separately, and what people did weighed above what they said.
