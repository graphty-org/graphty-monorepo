5. Dropping a file on the window

A file dragged anywhere over the window selects the Open... row, which reads "Drop to open" until the drop. Nothing is read before then, and the page cannot tell what kind of file it holds, so the hint is the same for every kind. After the drop a data file goes to the load step, a project opens, and a recipe waits for data (state 4). The file icon under the pointer is the operating system's drag image, not part of graphty.
