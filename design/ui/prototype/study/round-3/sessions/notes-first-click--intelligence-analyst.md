# Session: first click for a note on a group -- Marcus, criminal intelligence analyst

Participant: Marcus, 44, criminal intelligence analyst at a state fusion center (persona in
study/personas/intelligence-analyst.md). Works in i2 Analyst's Notebook and Excel on call
records; expects every note on a chart to carry a source and a date.

Task, as the moderator gave it: "Write down why you kept this group, for next week."

Screens used: the Notes panel mock, starting from its first state (the empty panel, nothing
selected, a 300-protein sample graph drawn plain grey). The result of each click was read from
the page as a clickable prototype would show it.

## Problems seen

1. **The task's "group" does not exist on the first screen, and nothing says how to make one.**
   The empty panel says "Add a note about the selection" with nothing selected and no hint that
   a group (a set) must be built first. Severity 3.
2. **"Add note" arms a canvas tool instead of opening a text box.** The first click (the
   intended one) changes nothing in the panel; the switch into a note mode is only visible as a
   lit toolbar icon. Severity 3.
3. **In the Note tool, a click notes one node, so a group note silently becomes a note on one
   member.** Wrong target, discovered next week. Severity 3.
4. **Toolbar icons have no labels.** The square-with-dropdown and the route icon could be box
   select or not; he guessed. Severity 2.
5. **"Fixed set" is ambiguous** (repaired? frozen?). Severity 2.
6. **"travel in project files" reads as data moving on its own.** "Go with" would not alarm an
   analyst who has to account for where case data goes. Severity 1.
7. **Notes cite a measure but carry no source record, calendar date or grade.** Severity 2.

## What worked

- The empty panel says notes are saved in the project and leave only with project files and
  reports -- the question he asks first about anything he writes.
- The finished group note (seen only by jumping to another state) is what he wants: a named
  group of 33 built from "neighbors of" one person, with the note saying which measure and which
  graph it rests on.
