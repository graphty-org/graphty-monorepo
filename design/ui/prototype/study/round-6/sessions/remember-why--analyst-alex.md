# Leave yourself a note on why you kept these accounts -- Analyst Alex

Participant: Analyst Alex (operations data analyst; Python, Excel and Gephi; sceptical, five-minute
patience).

Task as given: "You kept these accounts aside for a reason. Leave yourself a note on why, so you
remember next week."

Screens seen, in the participant view (design notes hidden): Take a note (all eight states), the
Notes panel (all eleven states) and Sets and paths (all nine states). Each state was rendered
fresh for this session.

## Single Ease Question

**5 out of 7.**

"What took longest was finding where to start -- four unlabeled icons on the set, and then it's the
last thing in the dots menu. After that it was easy, and next week I'd find it, the Notes list
with search is fine. I'm taking points off for 'Saving as: Marcus', which made me wonder whose
account I'm in, and for not knowing if the note comes out with my Excel export."

## Would you use this instead of what you do now?

"What I do now is a markdown cell in the notebook, or a comment on the Excel sheet, or honestly a
sticky on my monitor. For 'why did I keep these 14', yes, I'd use this, if I'm already doing the
work in here -- because it's stuck to the actual set, it wrote down the PageRank settings for me,
and it told me when April changed my number. Nothing I use now does that last part. My notebook
comment just goes out of date and I don't notice."

"But it's only a yes if the note comes out with the export. If it lives only in this app, it's a
reminder for me, not something I can hand over, and handing it over is the job."

## Moments, briefly

- Hardest step: finding the starting point (unlabeled icons on the set header; Add note is the last
  item in the overflow menu). The labeled Notes button on the left rail would have been his first
  click.
- Best moment: the "Earlier data ... now 0.000428 in April's data" line on a quoted number.
- Worry: "Saving as: Marcus" -- a name he did not give, in a tool he has not signed in to.
- Open question he could not answer from the screens: does the note go out with the table export?
- Inconsistencies he noticed: a sticky-note icon on the Sets and paths toolbar that appears nowhere
  else and has no tooltip; a set with a Notes section on one screen and none on another; note rows
  laid out date-first on one screen and "About"-first with an author on another; the Notes panel
  screen shows a different project (proteins).
