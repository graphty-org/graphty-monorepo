# Tier 2 first dry run before round 2: the detours, by pointer and by keyboard

Round 1's dry runs walked only the answer key's routes, and participants met build defects on the
detours they took instead. This dry run walks every task's success path and the wrong turns round
1's participants took most often, once by pointer and once by keyboard, pressing Enter, Tab and
Escape in every field it opens. It also gives each fault that only one round 1 session met a
script before calling it a defect, and re-walks tier 1's open-your-own-file task.

The walks are a script, `pilot/detours.sh`, so the study tool runs the same detours on any build:
`REAL_DIST=<build> pilot/detours.sh all` (30 walks, about 25 minutes at three at a time). Each walk
checks the screens it should reach; `FAIL` names a fault a participant could meet. The walks per
task are listed in `tasks.md`, "Detours the dry run walks".

# Pilot of every task on the frozen build ddf8b3b63, and what is fixed before round 2

Every tier 2 task was piloted once per half (A and B) on the frozen round 2 build ddf8b3b63, plus
an expert walk-through of the path task. Pilots in `rounds/r2/pilot/<task><half>/`. Each defect a
pilot reported is listed below once, with its class and the reason:

- **fix: <group>** -- an implementation or polish defect a participant could hit. It is fixed
  before the first session, in the package that owns it, in the named group (listed after the
  table). The study build is frozen again after the fixes and re-piloted.
- **fixed** -- fixed in this pass already (the study tool).
- **design** -- a question the sessions exist to answer: where something lives, what a returning
  user expects, what to call it. Left alone so the sessions can answer it.
- **no change** -- the behavior is right or deliberate; the reason says why.
- **owner** -- already waiting on the owner in `../owner-decisions.md`.
