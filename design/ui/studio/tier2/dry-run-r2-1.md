# Tier 2 first dry run before round 2: the detours, by pointer and by keyboard

Round 1's dry runs walked only the answer key's routes, and participants met build defects on the
detours they took instead. This dry run walks every task's success path and the wrong turns round
1's participants took most often, once by pointer and once by keyboard, pressing Enter, Tab and
Escape in every field it opens. It also gives each fault that only one round 1 session met a
script before calling it a defect, and re-walks tier 1's open-your-own-file task.

The walks are a script, `pilot/detours.sh`, so the study tool runs the same detours on any build:
`REAL_DIST=<build> pilot/detours.sh all` (30 walks, about 25 minutes at three at a time). Each walk
checks the screens it should reach; `FAIL` names a fault a participant could meet. The walks per
task are listed in `tasks.md`, "Detours the dry run walks".
