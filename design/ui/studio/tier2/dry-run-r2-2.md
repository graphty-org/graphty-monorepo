# Tier 2 second dry run before round 2: every task piloted on build fabc16247403

Every tier 2 task was piloted once per half (A and B) on the frozen build fabc16247403, which holds
the fixes from the first round 2 dry run (`dry-run-r2-1.md`). Pilots are in
`rounds/r2d1/pilot/<task><half>/`. The pilots reported 102 items. Each is listed below once, with
its class and the reason. Before any item was classed, the cause the pilot gave was checked in
source or against the screenshot; five pilot claims did not hold and are marked so.

Classes:

- **fix: <unit>** -- an implementation or polish defect a participant could hit. It is fixed before
  the first session in the package that owns it; the units are listed after the tables.
- **design** -- a question the sessions exist to answer (where something lives, what a returning
  user expects, what to call it). Left alone.
- **no change** -- the behavior is right or deliberate, or the pilot's claim did not hold; the
  reason says which.
- **owner** -- already waiting on the owner in `../owner-decisions.md`.
- **process** -- about how the pilot ran, not the app.

## The fixes, by unit

- **Study tool** (`design/ui/studio/tool/`): launch Chromium without Playwright's
  `--hide-scrollbars`, so a pane that scrolls shows its scrollbar to participants as it would in
  a desktop browser (7, 57); `work.json` keeps a step's whole rule and names a run as the screen
  does (14, 15, 23); one length for control names in the tool's reports (43).
- **Import page** (graphty app): Add and Leave out stay where they are when "Show the 1
  unmatched row" is clicked (5).
- **Left-out inspector** (graphty app): the "1 row left out" inspector shows only its own row,
  not the whole source's counts (8).
- **Inspector notes** (graphty app): an explanatory sentence under an inspector row is drawn at
  the row's size, aligned with the row names (25).
- **Element selection** (graphty-element): the session notifies when the selection's origin
  changes even when its members do not (66); a `number-needs-backticks` suggestion is given only
  when the rewrite is itself a rule (68).
- **Find box** (graphty app): the refusal line starts where the hint and status lines do (71).
- **Section title** (compact-mantine): a cut section title shows the shared tooltip on hover,
  as a cut row does (76).
- **Neighbor list** (graphty app): one accessible name for the heading (77); the filter toggle
  shows a neighborhood filter on this node at any reach, and never stacks a second one (78).

The answer key is corrected where a claim did not hold on checking (38, 45, 81, 100).

Counted: 102 items. 15 fix, in eight units (5 of them in the study tool); 41 design; 40 no change,
4 of which are pilot claims that did not hold; 3 owner (one more claim that did not hold); 3
process. None of the 41 design questions was touched: they are what the sessions are for. After the fixes the build is frozen
again and every task is piloted again on it, T21B included.
