# Tier 2 third dry run before round 3

Every tier 2 task half (A and B of T4, T17 to T24 and T12R) was piloted again from its start on
build 26f3bb968e43 (`criteria.md`, first line), the build that carries the second round 3 dry
run's fix (`dry-run-r3-2.md`). The walks are in `rounds/r3d2/pilot/<task><half>/`. The pilots
reported 88 items, one row each below, with the class and the reason. Every item not already
classed in an earlier dry run was checked on its screenshot, and in source, before it was classed.

The question is the same as before: would a participant spend session time on a flaw in the build
instead of on what the task asks? No. Every success path landed, every reference value held, and
no walk logged a script error, a console error or a failed request. The second dry run's fix held:
under an on filter step the Overview's whole-graph rows sit under their own "Full graph" section
heading, with its own collapse arrow, below "Nodes showing" and "Edges showing" (T17B/07), so 77
no longer reads as the count drawn. Five items were new to the triages; each was checked and none
is a defect a participant would lose time on. This build needs no fix and no refreeze: it is the
build for the round 3 sessions.

Classes, as in the earlier dry runs:

- **fix: <unit>** -- an implementation or polish defect a participant could hit. Fixed before the
  first session in the package that owns it.
- **design** -- a question the sessions exist to answer (where something lives, what a returning
  user expects, what to call it). Left alone.
- **no change** -- the behavior is right or deliberate, or the claim did not hold.
- **owner** -- already waiting on the owner in `../owner-decisions.md`.
- **process** -- about how the pilot ran or what the answer key tells graders, not the app.

Reasons that recur are named once in `dry-run-r3-1.md` and `dry-run-r3-2.md` and used here by the
same names: **3D overlap**, **names by default**, **focus on a heading**, **covers until closed**,
**All N rows**, **hover under the pointer**, **tooltip on entry**.
