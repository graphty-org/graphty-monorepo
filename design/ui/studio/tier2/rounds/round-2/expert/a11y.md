## What holds

- **Round 1's focus fixes landed:** focus goes to the new step after Add step, to the next row
  after a delete (or to Filters "+" when none is left), and back to the row after Enter or Escape
  in the editor. Enter commits an edit and announces the new count. Escape from the Path popover
  returns focus to where it was.
- **Announcements:** the two-table load says "people and messages: 12 nodes, 22 edges, 1 row left
  out" from the persistent region. A replacement says "1 run out of date". The run state region
  holds only its words. A refused rule is polite. Filter on and off, the path found, a note added,
  selection counts and hops changes are all spoken.
- **Names:** each note's controls are named after the note ("Delete note: Call Farah Monday"). No
  two reachable controls on these screens share a name. Path From and To are typed comboboxes
  beside the canvas picks. Hops and Follow are labelled groups. The step checkbox is "Apply step:
  weight is at least 4".
- **Contrast:** every text checked passes 4.5:1. The lowest are the run row's "4 hops" on the
  selected row and the note's target chip (5.18 to 5.53:1), and the import table's "23 rows, 1
  left out" (5.53:1). The filter step row, editor captions, rule refusal (red, 7.20:1), import
  captions and the "Higher means" explanation are all above 6.6:1.
