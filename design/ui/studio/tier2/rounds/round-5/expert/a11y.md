## What holds

- **This build's fixes, verified by keys:**
  - Leaving an off step's editor for the Graph place leaves the step off: the drawing keeps all
    41 edges, the Overview reads 20 and 41, and nothing is announced (`filter-sr/53.png`, `55.png`).
    Round 4's severity 3 is closed.
  - With a step on, the Edges tab lists 12 rows and reads "12 of 41 edges"; turning the step off
    with the table open turns it into "41 edges" and 41 rows (`filter-sr/79.png`, `99.png`).
  - A layer made from the "or more" row is named "weight >= \`4\`", no longer "data.weight"
    (`path-sr/24.png`).
  - Cancel in the note editor puts focus on "Add note", and so does Escape on an empty editor
    (`path-sr/51.png`, `53.png`).
  - On bus stops, "10" highlights "Select where minutes is 10 or more (3)" first, its count in its
    name; Enter says "3 edges selected". No "=\`10\`" row is offered, on bus stops or on friends
    (`find-sr/04.png`, `05.png`; `replace-sr/27.png`).
  - New project, then Discard, opens the empty project, not the error page; the dialog opens on
    Cancel and focus returns to Main menu (`find-sr/11.png`-`15.png`).
- **Other holds:** Filters "+" puts focus in Keep; the disabled "Add step" is in the Tab order;
  Add step focuses the new row and says "Filter on ..."; the step's menu Delete sends focus to "+"
  and Undo restores the step as it was (off); From's pick moves focus to To; notes save by
  Control+Enter with "Note added about Shortest path"; Rerun returns focus to the heading; Escape
  steps out of the Path popover one level at a time back to Analyze; the two-table Load says
  "people and messages: 12 nodes, 22 edges, 1 row left out"; the data table is a grid that arrow
  keys walk from its column headers; the rail marks the current place with `aria-current`.
- **Contrast:** every new or changed text measured passes 4.5:1. Lowest: the selected step row's
  "off" 5.46:1, the Replace page's "All 41 rows" 6.53:1, the table's "In the order loaded" 6.81:1,
  the To box's "Choose a node" 6.92:1, "No nodes to draw" 6.97:1, the tab count "12 of 41 edges"
  7.59:1. The highlighted "or more" row reads 9.70:1. The header button's focus ring is a 1 px blue
  line all round, visible.
