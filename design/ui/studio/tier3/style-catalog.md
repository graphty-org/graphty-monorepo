# graphty-element style catalog

What this is: every style graphty-element has today -- every way the look of a node, an edge, a
label, an arrowhead or the scene can be chosen, and every look the element draws on its own --
with its exact name, value type, allowed values, default and where that default comes from, how it
can be set, and what limits it. It is a catalog only: no opinions and no proposals.

Source of truth: `origin/master` at `d6851450f` (fetched 2026-10-11). Every citation is
`path:line` relative to `graphty-element/` at that commit (a byte-identical copy of `src/` is in
`tmp/style-catalog/src-master/`). Section 11 lists what the unmerged branch `design/studio-tier1`
(pull request #1727, head `00a27ad9f`, merge base `4ba25fc9a`) adds or changes; its citations are
on that branch.

Facts marked "(ran)" were confirmed by running the master source (`tmp/style-catalog/verify/dump.ts`,
output `verify/dump.out`). Everything else is read from the code; where the code reading has not
been observed on screen, the row says so.

## 1. How a style is set (key)

| Key                  | Meaning                                                                                                                                                                                                                                              | Where it is defined                                                   |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| **S** (layer set)    | A style layer writes a literal value: `styles.add({ target, selector, set: { "<channel>": value } })`. Checked when the layer is added.                                                                                                              | `src/catalog/types.ts:654-664`; `src/session/styles/Layer.ts:540-640` |
| **E** (layer encode) | A style layer binds the channel to a data or result path through a scale: `encode: { "<channel>": { by, scale, palette, ... } }` (section 9).                                                                                                        | `src/catalog/types.ts:594-634`                                        |
| **C** (config)       | Not a layer: an element property or attribute, a `graph.set...()` method, the `config.set` command, or a `layoutBehavior` field. "C-project" = saved in a project file with an undo step; "C-view" = a preference of this view (no undo, not saved). | `src/graphty-element.ts`; `src/session/commands/config.ts:84-85`      |
| **I** (internal)     | A constant or decision inside the element; no public door reaches it (only raw Babylon access through `element.graph.scene`).                                                                                                                        | --                                                                    |
