## How the hard calls went

- **Pass incomplete.** Eleven reports say PASS INCOMPLETE. In every one the three routes were walked;
  what is missing is the report file (the harness refuses report files from subagents) or a route
  no session can take either (typing an address into the system file chooser, a clipboard paste,
  dropping a link: the tool answers a chooser only with a local file and its browser refuses
  clipboard reads). None leaves a task unwalked, so none counts as a block. The earlier
  `rounds/r1/pilot/<task>/report.md` files are stale; this triage holds the findings.
- **Graded around by the answer key is not the same as harmless.** The key already names several
  build defects and grades around them. Where the defect still leaves a wrong result on the final
  screen or in a saved file (the Data source card dropping every edge, the export scope counting
  nodes on an edge table, a weight the analyses ignore, a covered count), it is fixed now. Where
  the key's rule is settled design (a Select card selects across the whole graph), it is (n).
- **The inspector's time row** is drawn dimmed with its Set in Data button before a time is set and
  leaves the Overview after; the table header then carries the Time mark, so the result is on
  screen. Backlog, not (a); R10's door to Fields is not built (repeat).
- **Replace with a different file** keeps the first file's columns and issues under the second
  file's name. The key grades Replace from the Sources list, so grading holds; what Replace should
  do with a different file is a design question, and the round's bar 4 will see it as a severity 4
  candidate.
- **The camera moving to a pick** (find result, table row, right-click) is the owner's tier 3 glide,
  now written into tier 4's `decided.md`; how far it zooms is backlog.
