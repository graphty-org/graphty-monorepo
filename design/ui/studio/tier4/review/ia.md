# Tier 4 review: the Information Architect

Build e52d7c4f5748 (graphty@0.8.92), the studio worktree's `graphty/dist`, walked with `tool/real.mjs`
(GPU) on 2026-10-29. Walks (screenshots, not in git) under the main checkout's
`tmp/design-studio/tier4/review/ia/`: `w1` pantries.csv alone (Fields, Time, the table's header menu,
issues), `w2` pantries.csv + deliveries.csv (join, Data source card, Weight, Export), `w3` the start

Lens: where each data task lives (Data place, table, inspector, dialogs), naming, findability, the
order of steps. Cited rules: `decided.md` (owner rules for data UI), my notes ("one home, many
doors", door fidelity).

## Summary

The Data place holds Sources, Fields (roles) and Filters, but three data tasks still live outside it:
a column's type (table header menu only), the data issues and their fixes (table only), and roles
(three homes with two different lists). Two doors land on the wrong place (Open network data's
three cards all open the Server form on Neo4j; no web-address door inside a project). The Data
source card hides every edge when it keeps the first file's nodes.

## Seen and not reopened

- The card's "Hide" keeps what matches and hides the rest (`design/data/filter-cards.md`, Hide writes
  `effect: "keep"`), so "Hide" with pantries.csv ticked shows pantries' nodes. A reader may read it as
  "hide pantries.csv". Owner-decided (option B, 2026-10-29); watch it in sessions, no change now.
- The count of a filter appears on the card, in the top bar, in the inspector ("Nodes showing 12 of
  13") and the table ("12 of 13 nodes"). All four agree on this build, which tier 2 asked for.
- Export is in the main menu with its key (Ctrl+E) shown: the hotkey rule holds.

## Proposed order, if only a few are taken

1. Findings 4 and 5: a wrong picture and a wrong door, each a small fix in its owning package.
2. Findings 1, 2 and 3 together: Fields becomes the one home for type, role and issues (one change to
   one panel, with the table and inspector left as doors).
3. Finding 6: the web-address door inside a project, reusing the start dialog's control.
