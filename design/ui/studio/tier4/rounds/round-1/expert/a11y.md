# Tier 4 round 1: accessibility walkthrough

and with the screen-reader text (`--sr`, `--read`, `--expect described=`), light theme at 1440 x 900, plus
a pointer session at 900 x 700. Contrast in both themes and both sizes is taken from the scripted axe walk

wrong with no sign, 3 blocked or misread, 2 friction, 1 cosmetic or wording, 0 not a problem).

## Severity 3

**1. Export with a format warning drops focus and says nothing (export dialog).** Enter on Export with CSV
chosen and style layers present shows "Styles lost in CSV" (an `alertdialog` drawn inside the Export dialog)
and does not save. Focus falls to the page body; no live region or alert is spoken, so a screen-reader user
hears nothing after pressing Export and has no sign the file was not written. The next Tab walks the page
behind the modal (Main menu, Project, Undo...); about 48 Tabs later focus re-enters the dialog and is then
trapped between Save anyway and Choose another format. Raised from the backlog's 2 because for a
screen-reader user the export looks done and is not (a result a reader would misread). Confirmed: expert
finding plus scripted repro. Evidence: `a11y/k5/23.png` (focus: the page), `a11y/k5/24.png` (ring on Main
menu behind the dialog, warning visible), `a11y/k5/route.jsonl` steps 23-74. Owner: graphty app (move focus
to the warning's first action and give the warning `role=alert` or route it through the app's status line).
Backlog rows T68A-1, T68A-2, T68B-1 (pass 8).

## Severity 2

**2. Critical axe finding on every data screen with the table open (bar 5).** The table's Nodes tab
carries `aria-controls` naming a tab panel that is never rendered: `graphty/src/workspace/table/TableDock.tsx`
703-722 renders `Tabs` / `Tabs.List` / `Tabs.Tab` with no `Tabs.Panel`, and Mantine always writes
`aria-controls`. axe rates it critical (`aria-valid-attr-value`) on Sources +, both web address routes from
Sources +, the join screen, the issue list, Fields +, the Filters picker and Export on Data, at both sizes
and both themes. Real effect for a reader is small (a "jump to controlled element" command goes nowhere), so
severity 2, but bar 5 fails on it alone. Fix in the app: wrap the grid in one `Tabs.Panel` for the active
value (or drop `aria-controls` by giving the strip its own tab panel id). Evidence: `../bars/bars.json`,
`../bars-light/bars.json` (`tier2.screens`). Owner: graphty app.

**3. The web address load drops focus to the page (T60).** Enter in the address box opens the network and
focus goes to the page body; the next Tab starts at Main menu. The polite status is written twice
("sources: 24 nodes, 59 edges", then "24 nodes, 59 edges" into a region that arrived filled). Evidence:
`a11y/k1/49.png`, `a11y/k1/route.jsonl`. Confirms T60A-1 and T60A-2. Owner: graphty app.

**4. F6 never reaches the top bar and enters regions on a resize separator.** F6 cycles left panel,
inspector, canvas, canvas toolbar, and, with the table open, enters the table on "Resize table" instead of
its first control; it never stops on the top bar (decided: five regions, a resize handle is never a region).
The left panel is entered at "Add source", not its first control. Evidence: `a11y/k1/route.jsonl` (after
49.png), `a11y/k2/69.png`, `a11y/k3/06.png`. Confirms T60A-3, T63A-5, "F6 after a resize separator".
Owner: graphty app.

**5. Escape on the join screen cancels the join and sends focus to the inspector.** With focus on Join,
Escape cancels the whole join ("Join canceled", with an Undo button on the notice); Control+Z then does
nothing, and focus lands on the inspector's "From pantries.csv", not on Add source, which opened the flow
(2.4.3). Evidence: `a11y/k2/65.png`. Confirms T61A-2; the focus target is new. Owner: graphty app.

**6. The join screen's selects open on Tab and cover the summary chips.** Tabbing into Source column,
Source graph value, Target column and Target graph value opens each list (`expanded`), hiding the "1 new
node" chip. Evidence: `a11y/k2/23.png`. Confirms "Fields and Join selects" and T61A-18/20. Owner: graphty
app (use the compact-mantine combobox the condition cards use).

**7. Join has no description; "19 of 19 rows" is spoken on arrival.** The focused Join button's
description is empty, so what Join will do (the chips row) is not heard with it; the status says "19 of 19
rows" as the screen opens. Evidence: `a11y/k2/18.png`, `a11y/k2/64.png`. Confirms T61A-1 and the "Load and
join announcements" row. Owner: graphty app.

**8. A table header's issue is not spoken on focus.** The focused "mixed families" header is described
"92% filled 12 unique" and the Edges table's "Key Target" header has an empty description, though each
carries an issue mark (browse mode reads "Issues in ..."). Evidence: `a11y/k3/19.png`, `a11y/k3/53.png`.
Confirms T61B-1 and "Table header issues and keys". Owner: compact-mantine DataTable (additive ARIA).

**9. The column menu's key is not named anywhere.** The header menu (the only place that sets a column's
kind from the table) opens by Shift+F10, ContextMenu or Alt+ArrowDown; the "..." shows on focus but is not a
Tab or arrow stop, has no tooltip, and the header has no `aria-keyshortcuts` or description naming the key.
Evidence: `a11y/k3/20.png` (menu by Shift+F10), `a11y/k3/39.png` (focused header with its "...").
Confirms T62A-4. Owner: compact-mantine DataTable (TooltipShortcut on "...", per the team decision).

**10. Tab in an open Fields list does nothing; a new Time line says "collapsed" while open; Space removes
it.** With the Id list open, Tab leaves it open (decided: Tab closes it and takes nothing). After Add to node
fields > Time the new box announces `collapsed` while its list is open, and Space on the highlighted option
removes the empty line instead of choosing it, with nothing announced. Evidence: `a11y/k3/route.jsonl`
(Id list), `a11y/k3/101.png`, `a11y/k3/102.png`, `a11y/k3/103.png`. Confirms T63A-2, T63B-2, T63B-4. Owner:
graphty app (Fields.tsx's plain Mantine Select).

**11. Fields row names take three forms.** "Id", "Node latitude column" and "Node time" sit in one block.
Evidence: `a11y/k3/route.jsonl` (focus lines after 71.png). Confirms T63A-10 and "Fields row names". Owner:
graphty app.

**12. Data panel sections are not headings; the rail does not say which place is open.** Sources, Fields
and Filters are read as collapse buttons or plain text, never headings; Graph, Data and Notes report no
current or pressed state. Evidence: `a11y/k1/78.png` and its `--read` lines in `a11y/k1/route.jsonl`.
Confirms "Data panel sections" (compact-mantine ControlSection) and "Left rail" (graphty app).

**13. Export's kind list is a grid of cells.** Image, Video, Data, Styles, Recipe, Project are read as

Confirms T68B-3 and "Export kinds". Owner: graphty app (vertical tablist).

**14. The filter card's count chip is not reachable.** "15 of 24" is drawn on the card but is neither a
Tab stop nor in any focused control's name or description; a keyboard screen-reader user hears it only in
the live status. Evidence: `a11y/k4/78.png`, `a11y/k4/route.jsonl`. Confirms T65A-1. Owner: graphty app
(put the count in the card group's name or the effect control's description).

**15. Icon buttons with no tooltip.** The source row's warning chip ("1 issue in deliveries.csv"), Table
options, Maximize table, Close table, the header issue mark ("Issues in families") and the address box's

`a11y/k6/11.png`. Confirms T67A-1, T67A-2, T63A-9, T60A-3. Owner: graphty app (compact-mantine for the
DataTable header mark).

**16. Narrow window: the table strip cuts the Edges tab and Columns; Maximize overlaps the inspector.**
At 900 x 700 the strip draws "Edge" under the With issues chip, "C..." for Columns and no count; maximized

**17. The Server form gives no reason for dimmed Load and Test.** Kind Web API: Load and Test are dimmed
with no tooltip; a pointer-opened form does not take focus. Evidence: `a11y/k6/13.png`, `a11y/k6/15.png`.
Confirms T60A-5 and T67A-19. Owner: graphty app.

**18. The issue list and source row names read glyphs as words.** The source row reads "deliveries.csv 17
