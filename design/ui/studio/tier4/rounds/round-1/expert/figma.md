# Tier 4 round 1: Figma product designer walkthrough

Build 79ed770292 (graphty@0.8.92), the frozen study build, walked 2026-10-30 with `real.mjs` on the
GPU at 1440 x 900, default color scheme. Four sessions, every one ended; screenshots under
`expert/figma/` in this round's folder:

- `w1/` (empty start): the start screen's Open network data, the web address box, sources.graphml
  from its address, the Data place, Sources "+", Network data..., Server...
- `w2/` (setup `pantries.txt`): Fields, Fields "+" Time, the source row's issue list, Filters "+",
  a date card and a text card, the table header menu and Type, Sources "+" > File... deliveries.csv,
  the join screen and its count chips, Join, the source rows after the join, the source row menu,
  Export from the row and from Control+E, the Scope and Format lists.
- `w3/` (setup `volunteers.txt`): the toolbar's Filters button, a yes/no, a number and a category
  card, Select on the third, the Style panel's held Which nodes card, the top bar's filter chip.
- `w4/` (setup `pantries-joined.txt`): Filters "+" > Data source, ticking one file.

Lens: where Figma solved a control, a list, a menu or a properties row, the data screens should
work the same way; where graphty's model differs (sources, joins, condition cards), the data
screens should match graphty's own Style panel. Severity: 4 data lost or wrong with no sign, 3 a
reader would misread or a common route blocked, 2 friction, 1 cosmetic or wording.

## What already works the Figma way on this build

- The toolbar's Filters button is a door: it opens the Data place with the Filters picker open
  (`w3/03.png`).
- Filters "+" is the Style panel's attribute picker: search shown and taking typing, kind glyphs,
  value summaries, a Structure group with Data source (`w2/09.png`, `w4/02.png`).
- Turning cards on, adding cards and ticking a source never move the camera (`w3/07.png`,
  `w4/04.png` against their first screenshots).
- Sources "+" and the source row menu use the menu grammar: glyph left, key right
  (`w1/07.png`, `w2/35.png`).
- Choosing the Time sets only the Time; nothing else opens and the canvas keeps its size
  (`w2/04.png`). Fields shows one group per source after a join (`w2/26.png`).
- Category values read box, name, dimmed count right aligned; a Select card marks only what is in
  the picture and counts it ("4 of 14", 4 selected, `w3/11.png`).
- The issue list opens as a popover anchored to its row (`w2/06.png`).
