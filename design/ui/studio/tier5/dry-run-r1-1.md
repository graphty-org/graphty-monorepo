## How each defect was classed

- **(a) Fix now**: a crash, a block or a spoiled grade on a task's success path or a detour its pilot
  walked. Two readings of the rule were settled for this pass and written into `decided.md`
  ("Dry run pass 1, 2026-11-02"):
    - A severity 3 candidate that `criteria.md` item 8 names (the false "covered" claim, two count
      bases for one layer, the data table and the matches strip drawn together, a 50,000-node edit
      with no sign of work) is fix now: item 8 refuses every session while one is open, so it blocks
      every task. Each is classed by what it does (spoils, blocks, crash) and cites item 8.
    - A 50,000-node edit that blocks input with nothing on screen is classed as a crash ("a frozen
      app"): `criteria.md`, "Large graphs", says a reader takes it for a hang.
- **(n) Decided**: asks for something `decided.md` settles; no change.
- **(c) Backlog**: friction, wording, cosmetic, accessibility, and every defect only a keyboard or
  screen-reader user meets. Appended to `backlog.md`. A row marked "decided, not built" breaks a
  behavior `decided.md` already settles; those go first in the decide-and-fix loop.
- **(b) Design question**: left for the sessions.
- **T76 runs in no session** (`criteria.md`: "T76 runs in the dry run only"), so nothing on a T76
  route can spoil a grade; every T76 row is backlog, with a note where it is a wrong result.
- **Origin** (fix now only): new; repeat (an earlier fix round of this tier already sent the same
  problem to be fixed, and it is back); regression (none: this is the first dry-run pass).

  built (workspace polish 2, "Pickers under fields never flip"). Escape closes the picker and Done is
  back; a pick still works. Backlog, first in line.

  and 4: the drawing moves only when the reader asks; `interaction-patterns.md` line 322). Every count
  a task grades is in the inspector, the header or the top bar, not counted off the canvas. Backlog.
- **A resting filter card does not open on a click of its row; Edit is not drawn on hover** (T71A,
  T71B, T75A, T77B). Decided, not built (placement, "Edit, a click or Enter on any row opens the
  workspace"; workspace polish 1, "Sidebar Edit is drawn on hover or focus"). A first click draws
  Edit and a second opens it; T77 B's path counts 15 steps for it. Backlog.
- **A layer made from a canvas selection opens the older inline card and picker** (T70B, T73B,
  T79A). Decided, not built ("One editor and one value picker in both hosts"). Every route through it
  still reaches its count; graded P where the answer key says so. Backlog.

  T70B, T71A, T71B, T75A, T75B). Every route that uses it is "not success" in `answers.md`, which
  grades a count read from it as the count it is. Backlog.
- **T75 A's Largest component has no So far** (T75A.12, T75B.4). Not a block: the Piece size route
  was walked to S on this build ("105 of 549"), so `criteria.md` item 8's "T75 A blocked" no longer
