## How the counts were made

The budget is tier 4's `../tier4/words-at-rest.md` as tier 5's criteria apply it: the selection
workspace open on a step, **40** app words at most, counted apart from the screen behind it; the
whole screen at rest (the read-only outline, the workspace closed), **50** at most; every heading
**3** at most. Over budget is a severity 2 calm-first finding (bar 9).

Each count below is a hand count, following the method in `words-at-rest.md`: app words only, a
word is a run between spaces, placeholders count (they are visible), numbers do not. Not counted:
the person's own attribute names, values, node names and ids, layer names ("Layer 1",
"PageRank"), result names ("PageRank", "Connected components: Piece"), the group letters A, B, C
(names of the reader's own groups), and the matches strip's cells. The scripted count
(`measure.mjs` `wordsOnScreen` on `.sel-ws`) is given beside it; it runs higher because it counts
"Yes"/"No" cells and group letters and leaves out placeholders.

## Verdicts on the fix pass's new words

| Phrase                                         | Verdict                                                                                                                                                                                                                                                                                                                              |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| "And..." (a group that starts with everything) | **Keep, with a change.** On its own, beside "All nodes", it reads as "and also must", which narrows. The problem is that it sits in the same place as "Add..." and differs from it by one letter. "Keep..." would match the step's own verb and say "narrow" outright. Round 2 should check both.                                    |
| "Add..." (a group that starts with nothing)    | **Change.** Its meaning is right, but beside "Or..." both read as "bring in more". "Add to B..." tells the two apart.                                                                                                                                                                                                                |
| "Or..."                                        | **Keep.** Read with the outline's "or" between colored groups, it says "another way in".                                                                                                                                                                                                                                             |
| "Highest" / "Lowest"                           | **Keep the words, fix the box.** They are plain and say which end, but at 1440 x 900 they show as "Hig..." / "Low...". The outline says "bottom" for "Lowest".                                                                                                                                                                       |
| "nodes" / "% of nodes"                         | **Keep, fix the box.** Plain, and they say what the count is. Cut to "% of nc" in the filter pane.                                                                                                                                                                                                                                   |
| "Nothing is cut until a count is typed."       | **Keep in the filter host. Change in the style host**, where nothing is cut: "Every node still matches until a count is typed."                                                                                                                                                                                                      |
| "Pick or type a color"                         | **Change to "Pick or type".** The meaning is plain, but it is cut ("Pick or type a co...") and repeats the row label "Color".                                                                                                                                                                                                        |
| "Done (Escape)"                                | **Keep.** It is the tooltip of a visible Done button, so the key has a visible button, as the owner's rule asks, in Figma's hints-in-tooltips pattern. Seen on hover over Done (`style/38.png`).                                                                                                                                     |
| "Connected components (N visible)"             | **Keep the idea, change the word and the fit.** It does say which run: the one over the nodes showing now. But the screen's word for those nodes is "showing", the scope is cut in the picker row, and the scope is gone from the step once the entry is picked. Use "(112 showing)", keep it whole, and carry it into the step box. |

Rule check across every selection-editor screen walked: no "links" or "ties", no "Select",
"Filter to" or "Filter out", no sentence at rest (the only sentences are the refused-count errors,
shown only after a bad entry), and no hotkey without a visible button. The three violations found
are outside the editor, on the Analyze popover and the canvas legend.
