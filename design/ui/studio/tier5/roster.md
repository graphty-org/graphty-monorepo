# Tier 5 participants: returning users choosing which nodes

Simulated participants: each session is a fresh agent playing one persona, with no memory of any
other session. What makes a persona "returning" is the history below, which the participant is
given word for word with its persona file. No real person is portrayed; the persona files are
composites built from public sources.

Paths: `S/` = `design/ui/studio/personas/` (this worktree); `P/` = `design/ui/studio/personas/`
(the same folder: the four files tier 4 read from its own worktree are in this one); project
records (designloom): `design/designloom/personas/`.

## Who takes part, and why these seven

The same seven as tier 4, one month on, so every one of them has met the data features and the
old condition cards, and none has met the new way of choosing.

- **Grace** (nonprofit operations) and **Dana** (supply-chain risk, helping a friend's food bank):
  the volunteer list, where choosing people by role, hours and training is weekly work. They take
  the people half of the core tasks.
- **Ruth** (reporter): her sources network, colored for an editor and shown in a meeting.
- **Tom** (lab manager who keeps the river project's map, `recipe-recipient.md`): reads every
  confirmation, changes nothing he does not understand; the careful newcomer on the river half.
- **Maren** (genomics researcher who knows Cytoscape, `genomics-cytoscape-user.yaml`): Cytoscape's
  Select and Filter panels are daily work; she shows where that expectation meets graphty. Her
  yeast network, and a colleague's river project.
- **Alex** (operations analyst who knows Gephi and NetworkX, `analyst-alex.yaml`): expects Gephi's
  filter chains (giant component, degree range) and measures by position; he takes the big network
  and the measure tasks.
- **Sam** (keyboard only, `keyboard-only-sam.md`): two tasks with every pointer step refused
  (`--keys`), for bar 5: one choice in each host (T70) and a second way in, in a filter (T71).

## How the histories are written

Each history names only places earlier tiers reached (the start screen, "Open a file", the left
rail's Graph and Data, the find box, the table from the toolbar, the Style tab, Analyze, Save and
Recent projects, the Export dialog, and tier 4's data features: putting two files together, the
Data place's filter cards). It never names a tier 5 control: no step, group, verb, "Or", start
with, so far, reference, preview, group colors or the add menu's presets. Each history accounts for
every start the persona is given: a project set up by a colleague or a friend is one the person has
opened and looked at, never built. Every history ends: "Anything you have not done before is as new
to you as it was the first day."

## Where each session starts

Each start is the person's own project as they left it last time, or as the colleague or friend in
their history shared it (setup files in `../rounds/tier-5/setups/`; the participant never sees
them). A Sam session adds `--keys` after the start (`setup:volunteers.txt --keys`).

- `volunteers.txt` (tier 4's): `volunteers.graphml`, 24 people, 63 ties, ranked by PageRank (a
  layer coloring all 24). No column is designated as the name, so the program names people by id
  (v01 to v24).
- `sources.txt` (tier 4's): `sources.graphml`, 24 people and organizations, 59 ties.
- `gauges-clean.txt`: gauges.csv and flows.csv put together, Stone Weir's bad depth made blank,
  `installed` read as dates, G12 (only in flows.csv) removed with its stretch, and `station` as
  the name: 11 gauges, 13 stretches, one piece, directed.
- `gauges-telemetry.txt`: `gauges-clean.txt`, then a filter card (telemetry yes, Filter to: 7 of 11)
  and a layer named Oldest coloring the gauges put in before 2000 among them (2 of 7) in E4572E.
- `volunteers-thanks.txt`: `volunteers.graphml` (no ranking), then a filter card (trained Yes, then
  hours 10 or more, Filter to: 14 of 24) and a layer named Staff coloring role staff among them
  (4 of 14) in E4572E.
- `researchers.txt`: the start screen's Graph researchers sample, 549 people, 2,084 ties (369
  repeated), one piece.
- `yeast.txt`: `yeast-galactose.graphml`, 331 genes, 361 interactions, 26 pieces (the largest 249).
