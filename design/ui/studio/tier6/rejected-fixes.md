## Rejected: panel-names-say-what

Unit: give each Assistant panel control a name of its own (`panel-names-say-what`, graphty). Each control in the Assistant panel -- the composer, the waiting line, the Undo at the end of a turn, the top-bar Undo and Redo -- names what it acts on (fix 7062e1aeae with test follow-up a18bfee708, reverted by 5423eff810 and 69e6f402ac). Part of the words and Checks change landed in sibling commit 208e142062 and is still in place: refix it in the shared part, so one naming rule covers every control that undoes a turn.

- REGRESSION (route T93 B keyboard): the Undo button at the end of an Assistant turn takes its accessible name only from the turn's first change line. In this walk the turn computed connected components and then removed 82 nodes, so the button is named 'Undo: Computed Connected components for 331 nodes'. Pressing it also restored the 82 removed nodes and 63 edges (331 and 361 again, live 'Undid ...'). A screen-reader reader who wants to take back the removal hears a button that names only the computation, so they may not press it or may misjudge what it will undo. Before this change the name was plain 'Undo', which made no claim. The unit test only covers a turn whose first line is the removal ('Undo: Removed 12 nodes'), so it passes. Source: graphty/src/workspace/assistant/Checks.tsx line 373, aria-label={turnUndoName(lines[0])}. Possible fixes: name the line that changed the graph (a removal or an edit) ahead of a computed one, or name every line.
