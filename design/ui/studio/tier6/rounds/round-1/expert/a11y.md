## Severity 3

**1. Talk says "Listening" when nothing is listening (composer).** With no microphone, Enter on Talk speaks
"Listening"; the failure, "No microphone found.", is drawn under the composer and never spoken. Each further
press says "Listening" again. A screen-reader reader talks to nothing, believing it heard them: a wrong
belief, on the voice path that is meant as a first-class route. Evidence: `k1/139.png`, `k1/140.png`, live
lines in `k1/route.jsonl`; `Talk.tsx`, whose `end` handler calls `onLine` and sets no `announcement`. Applies
equally to a refused permission, by the same path (read, not run). Owner: graphty app for the spoken failure;
graphty-element to check, as a suspect, why `ai-voice-start` fires before the microphone is had.

**2. At 400% zoom the API key cannot be reached by pointer, nor seen by keyboard (Settings, AI provider).**
At 320 x 256 the dialog body shows only the section list, Done floats over it, and Tab to Provider, Model,
API key and Save never scrolls those fields in: typing goes into a field that is not on screen, with no
ring. The tool's own click on API key scrolled and was refused: `cm-modal-overlay intercepts pointer
events`. The Assistant has no other way in, so a low-vision reader at 400% with a mouse is blocked at setup
(WCAG 1.4.10, 2.4.7, 2.4.11). A keyboard reader does finish, blind (`k6`). 200% is fine (`k7/04`), though its
fields scroll in a window about 130 px tall. Evidence: `k4/setup.log`, `k4/01.png`, `k5/05.png` to `k5/08.png`,
`k6/03.png`, `k6/04.png`. Owner: graphty app's Settings layout; suspect compact-mantine's modal body if the
stacking is the shared one.

## Severity 2

**3. Undo in a turn sends focus to the top bar, and typing then acts on the app (bar 8; backlog first in
line).** The button goes, focus lands on the top bar's now disabled Undo, and each letter typed is lost; `p`
opens Path between... from there (`k1/75.png`). Control+I recovers, so nobody is blocked, which keeps it at 2.
Evidence: `k1/67.png`, `k1/69.png`, `k1/74.png`. Owner: graphty app (raise `composerCalls`, as Change this does).

**4. Remove and Answer send focus to Jump to newest, which then has no box (bar 8).** `Waiting.tsx` raises
`composerCalls` only for Change this. Focus lands on the pill, typed letters are lost, and it stays until moved.
The focused pill is drawn with no fill over the transcript, so its words and the reply's overlap, unreadable
(`k1/112.png` to `k1/125.png`). This target differs from the earlier builds' (an old Undo, the log), so Enter
is harmless here, but the target is whatever lies nearest. Evidence: `k1/111.png`, `k1/121.png`, `k1/122.png`.
Owner: graphty app; the pill's lost box too.

**5. Old failures are spoken again, assertively, and run together.** On the next send, on closing the
conversations list (three alerts, `k1/142`, `k1/151`), on Save (`k1/183`) and on reopening the panel
(`k2/04`). Each reads "...was reached.Nothing changed.Send again": no space, and the button's name inside the
alert. Mechanism: the `role="alert"` rows remount or re-render with their text. Evidence: `k1/125`, `k1/129`,
`k1/130`, `k1/142`, `k1/151`, `k1/183`. Owner: graphty app.

**6. Send again leaves focus on the scope x.** Enter on Send again lands on "Ask about the whole graph"
(`k1/128`), so a second Enter silently widens the next message's scope. Backlog had the log; it now moves
by what is near. Owner: graphty app.

**7. Esc that closes Settings also clears the selection.** With focus on a dialog button or radio, one Esc closes
the dialog and fires `selection.clear`: "Selection cleared: 4 nodes", and the scope line goes to Whole graph
(`k1/161.png`; repeated, `k2/12`, 1 node). Selection cannot be undone and is the next message's scope; the
command's own comment says each dialog takes its own Esc. From a combobox or the composer it does not happen
(`k2/09`, `k1/154`). Any reader meets it. Owner: graphty app.

**8. The scope x is lost by closing the panel.** x, then Control+I twice, gives Selection again with nothing
spoken; "Remove every node whose role is volunteer" then ran on the selection, removing 1 of 16 (`k1/96` to
`k1/99`). `Composer.tsx` forgets the x on unmount, and Control+I is this panel's own toggle. Owner: graphty app.

**9. A refused key is silent.** Save with a bad key keeps focus on Save, and "OpenAI keys start with sk-." or
"This key is too short." reaches only the field's description: no live line. A reader hears nothing after
Save. Evidence: `k1/176`, `k1/177`, `k1/179`, `k1/182`. Owner: graphty app (move focus to the field; the
description then reads).

**10. Delete's confirm puts focus on Delete, and the question is not spoken.** The row's Delete then Enter lands on
a second "Delete" with no description, so Enter Enter deletes a conversation for good; "Delete this
conversation?" is plain text beside it. Evidence: `k1/145.png`, `k1/188`, `k1/189`. Owner: graphty app.

**11. Control+I with Settings open moves focus behind the modal.** Focus goes to the composer under an open
`aria-modal` dialog (`k1/153.png`). Backlog row confirmed. Owner: graphty app.

**12. Open run gives no signal.** Enter keeps focus and the inspector changes; nothing is spoken and the Style
tab is empty of the answer (`k1/63.png`). Open layer goes by the same route, not pressed here. Owner: graphty app.

**13. Row actions carry no context.** "Undo", "Remove", "Change this" and "Keep them" name nothing, though the card's
title is one id away. Focused alone, Remove says only that. An `aria-describedby` to the title and an Undo named
for its change line fix both. Evidence: `k1/105` to `k1/107`, `k1/53`. Owner: graphty app.

**14. The show-key eye is out of the tab order and named "Show the password".** Confirmed: Tab goes from API key to
the link (`k1/20`). Keys are not passwords, and a typing reader cannot check one. Owner: graphty app, by the
field's own `visibilityToggleButtonProps` and a label for this use; compact-mantine's default stays as locked.

**15. At 320 wide the panel runs off screen.** Send, Talk and the x are cut at the right and the page sits offset
(`k6/06.png`, `k6/07.png`, `k5/03.png`), where design 3.4 has it fill the area right of the rail. Enter and Control+I
still work, so it is friction. Owner: graphty app.
