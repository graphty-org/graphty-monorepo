**Goal:** Make graphty-element USE the accelerator it already knows how to find. The version 2 element branch (`feat/element-api-2`) ships the whole detection half of the WebGPU design: an optional peer, a `./webgpu` entry point that registers a factory, an `AccelerationController` that probes, attaches, watches device loss and publishes `capabilities.acceleration`, an `acceleration` attribute and a `graphty-capabilities-change` DOM event. Master ships the two seams that half was written for: `@graphty/layout` 1.8.0's `createSimulation` / `LayoutSimulation` and `@graphty/algorithms` 1.8.1's `accelerated()`. Nothing joins them: no layout and no algorithm run on the element ever calls `controller.plan()` or `controller.run()`. This plan lands the join -- the force layouts `forceatlas2`, `spring` (Fruchterman-Reingold) and `spring-electrical` driven through the layout simulation seam on the CPU or the GPU, five algorithm adapters through `accelerated()` with the result's precision labelled, one controller shared by the element and its session, the release of GPU buffers when the snapshot is replaced, play / pause / reheat, the drag and pin paths, the fake accelerator, the stories, the browser tests on SwiftShader and on the NVIDIA card, and the G6 gate record.

**Architecture:** graphty-element owns WebGPU detection, construction, attachment and recovery (root `CLAUDE.md` "WebGPU"; `design/decisions/2026-09-19-graphty-element-owns-webgpu.md`). The GPU package is an OPTIONAL peer imported by exactly one file, `graphty-element/webgpu.ts`; the core imports the CPU packages' seam TYPES (`LayoutAccelerator`, `LayoutSimulation`, `AlgorithmAccelerator`) and their dispatchers (`createSimulation`, `accelerated`), which choose the CPU implementation only when no accelerator is attached and never after work has started (design 2.4). The decision "GPU or CPU" is taken ONCE per piece of work by `AccelerationController.plan()`, before the work starts; a failure after that point is the work's failure, reported with its code, never finished on the CPU in silence. The graphty app is HTML around the element and gets nothing this plan builds except through the element's public surface.
