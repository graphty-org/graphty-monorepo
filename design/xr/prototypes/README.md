# XR control prototypes: index of all 46

Every prototype keeps the same fixed setting: a solid colored background in full VR, the graph floating
at chest height about 70-80 cm away, on a head-mounted display with hands, controllers where the device
has them, eyes where exposed and optional voice. They differ only in interactions, controls and menus.

Kind says where the idea comes from: metaphor (a real-world thing the controls imitate), plain (a plain
idea with no metaphor; "combination" when it joins several plain ideas, "product" when it borrows one
product's controls), paradigm (built from the interaction paradigms in `design/xr/`), research (from
published research or an existing project), usage (a new usage paradigm: a different way of working,
not a different control), hybrid (made by the design studio from parts of other prototypes).

The studio's evaluation of all of them is [the XR prototype studio report](../xr-prototype-studio.md).
