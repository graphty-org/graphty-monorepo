## Every importer

`CommonImportOptions`: every importer accepts these next to its own options.

| Option              | Type                                                            | Default       | Meaning                                                                                                                                                                                                                                                                                                                                                                     |
| ------------------- | --------------------------------------------------------------- | ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ids`               | `IdCoercion`                                                    | `"canonical"` | Id coercion rule applied before an id reaches the sink: "canonical" by default for text-cell formats, "keep" for JSON.                                                                                                                                                                                                                                                      |
| `nodeIdFrom`        | `"id" \| "label" \| "index"`                                    | `"id"`        | Which field becomes the node id; "id" by default; "label" / "index" resolve the GML / Pajek / d3 ambiguity.                                                                                                                                                                                                                                                                 |
| `addMissingNodes`   | `boolean`                                                       | `true`        | Whether an edge may reference an undeclared node (default true; the GEXF importer defaults false for edges).                                                                                                                                                                                                                                                                |
| `duplicateEdges`    | `DuplicatePolicy`                                               | `"keep"`      | The builder's duplicate-edge policy seed; default "keep".                                                                                                                                                                                                                                                                                                                   |
| `selfLoops`         | `"error" \| "keep" \| "drop"`                                   | `"keep"`      | The builder's self-loop policy seed; default "keep".                                                                                                                                                                                                                                                                                                                        |
| `onMixedDirection`  | `"directed" \| "undirected" \| "error" \| "expand"`             | `"expand"`    | What to do with a file whose edges disagree on direction; default "expand".                                                                                                                                                                                                                                                                                                 |
| `defaultDirected`   | `boolean`                                                       |               | The direction assumed for a file that declares none (GEXF: undirected per spec).                                                                                                                                                                                                                                                                                            |
| `weightFrom`        | `string`                                                        | `"weight"`    | The attribute that becomes THE weight (per-format default: "weight", GML "value"); null = unweighted.                                                                                                                                                                                                                                                                       |
| `weightDtype`       | `"f32" \| "f64"`                                                | `"f64"`       | Weight staging precision; "f64" for every importer by default so 0.1 and 16777217 survive.                                                                                                                                                                                                                                                                                  |
| `long`              | `"string" \| "f64"`                                             | `"f64"`       | How a declared `long` column is stored: "f64" (default) or "string".                                                                                                                                                                                                                                                                                                        |
| `restoreMangledIds` | `boolean`                                                       | `true`        | Restore ids mangled by sanitizeIds "mangle" from the graphty:originalId attribute (default true).                                                                                                                                                                                                                                                                           |
| `hyperedges`        | `"skip" \| "error" \| "star" \| "clique"`                       | `"skip"`      | GraphML / JGF hyperedges: refuse, skip with a report entry (default), or expand to a star / clique.                                                                                                                                                                                                                                                                         |
| `errorLimit`        | `number`                                                        | `100`         | Errors tolerated before the importer aborts with E_IMPORT (default 100).                                                                                                                                                                                                                                                                                                    |
| `signal`            | `AbortSignal`                                                   |               | Cancellation; the importer stops between chunks and rejects with the signal's reason.                                                                                                                                                                                                                                                                                       |
| `onProgress`        | `(bytesDone: number, bytesTotal?: number \| undefined) => void` |               | Progress in bytes; `bytesTotal` is known for in-memory input only.                                                                                                                                                                                                                                                                                                          |
| `encoding`          | `string`                                                        |               | The character encoding of byte input (a WHATWG label such as "utf-8", "windows-1252", "iso-8859-1", "utf-16le"); overrides the byte order mark and any encoding the file declares. Absent: a BOM decides, else the declaration (XML prolog, DOT `charset`), else UTF-8, and bytes that are not valid UTF-8 are read as windows-1252 with a warning. Ignored for text input. |

## Every exporter

`CommonExportOptions`: every exporter accepts these next to its own options.

| Option             | Type                                    | Default   | Meaning                                                                                                     |
| ------------------ | --------------------------------------- | --------- | ----------------------------------------------------------------------------------------------------------- |
| `sanitizeIds`      | `"error" \| "mangle"`                   | `"error"` | "error" (default): never rename a node; "mangle": rewrite ids the format cannot hold and keep the original. |
| `onMixedDirection` | `"directed" \| "undirected" \| "error"` | `"error"` | For formats without mixed-direction support: refuse (default) or write every edge one way.                  |

## importGraph and importAllGraphs

`ImportGraphOptions`: everything above, plus these, plus the chosen format's own import options.

| Option          | Type            | Default    | Meaning                                                                                                                                                                                                                                                                                                                                                                              |
| --------------- | --------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `format`        | `string`        | `"auto"`   | The format name, or "auto" (default) to sniff it from the filename, MIME type and content.                                                                                                                                                                                                                                                                                           |
| `filename`      | `string`        |            | The file name or path the input came from, a hint for sniffing.                                                                                                                                                                                                                                                                                                                      |
| `mimeType`      | `string`        |            | The MIME type the input was served as, a hint for sniffing.                                                                                                                                                                                                                                                                                                                          |
| `builder`       | `BuilderSeed`   |            | Builder options the common options do not cover (`weighted`, `expectedNodes`, ...).                                                                                                                                                                                                                                                                                                  |
| `freeze`        | `FreezeOptions` |            | Options of the freeze that follows the import.                                                                                                                                                                                                                                                                                                                                       |
| `maxEmptyCells` | `number`        | `16777216` | The most attribute slots that hold no value the import may allocate before it stops with E_TOO_MANY_EMPTY_CELLS. Every attribute is a column with one slot per node (or edge), so a file whose nodes each have a differently named attribute would otherwise need nodes x attributes memory. Default 2^24 (16,777,216); Infinity turns the check off. Dense files are never stopped. |
| `graphIndex`    | `number`        |            | The 0-based position of the graph, as `GraphListing.index` gives it.                                                                                                                                                                                                                                                                                                                 |
| `graphName`     | `string`        |            | The name of the graph, as `GraphListing.name` gives it; a name two graphs share is refused.                                                                                                                                                                                                                                                                                          |
