# Amazon S3

::: warning Experimental
Network sources are experimental: the source id `s3`, its parameters and what it lists may still
change.
:::

The `s3` source reads graph files kept in an Amazon S3 bucket: it lists the bucket's files and loads one of them, in whatever format graph-io reads. graph-io detects the format
from the file's name and its first bytes, exactly as it does for a file you open. It works in Node
and in browsers.

It is not one of the built-in sources, so import `s3Source` from `@graphty/graph-io/sources/s3`
and pass it to `listFromSource` and `loadFromSource` (or register it once with
`registerSource(s3Source)` to call it by its id, `"s3"`). For example,
`loadFromSource(s3Source, { bucket: "my-graphs", key: "data/network.graphml", region: "us-east-2" })`
loads `https://my-graphs.s3.us-east-2.amazonaws.com/data/network.graphml`.

Requests are not signed unless you pass a signing credential (see Private buckets), so without one
the bucket (or the files) must allow public reads. A web page can read
the bucket only when the bucket's CORS configuration allows the page's origin and the `GET` method;
otherwise the browser blocks the request and the load fails with `E_SOURCE_BLOCKED`.

## Parameters

| Parameter | What it is                                                                                      |
| --------- | ----------------------------------------------------------------------------------------------- |
| `bucket`  | the bucket's name: lowercase letters, digits, dashes and dots; required                         |
| `key`     | loading: the file's key (its path in the bucket); required. Listing: a folder to list           |
| `region`  | the bucket's AWS Region (`us-east-2`); without it the global address `s3.amazonaws.com` is used |

A bucket whose name holds a dot is read from the path-style address
(`https://s3.us-east-2.amazonaws.com/my.graphs/...`), since its own address would not match S3's TLS
certificate. `s3BucketUrl({ bucket, region })` gives the address a bucket is read from.

## Private buckets

A private bucket's requests are signed with AWS Signature Version 4: pass
`credentials.awsSigV4({ region, service: "s3", credentials })`, bound to the bucket's address.

```ts
import { credentials, loadFromSource } from "@graphty/graph-io";
import { s3BucketUrl, s3Source } from "@graphty/graph-io/sources/s3";

const params = { bucket: "my-graphs", key: "data/network.graphml", region: "us-east-2" };
const credential = credentials.awsSigV4(
    { region: "us-east-2", service: "s3", credentials: { accessKeyId, secretAccessKey, sessionToken } },
    { origins: [s3BucketUrl(params)] },
);
const { snapshot } = await loadFromSource(s3Source, params, { credential });
```

The credentials need `s3:GetObject` to load and `s3:ListBucket` to list. In a browser, only
temporary credentials (with a `sessionToken`, from a Cognito identity pool for example) are used;
long-term keys are refused with `E_SOURCE_PARAM`. `credentials` may also be a function that returns
fresh ones for each request. The signature goes only to the bucket's address.

## Listing

`listFromSource(s3Source, { params: { bucket, key, region }, search, size, cursor })` lists the
files under the folder `key` (the whole bucket without it), `size` at a time (100 unless you say, at
most 1,000). Folders are not listed. Each item's `name` is the file's key and its `params` load it.
`next` is the `cursor` of the next page, or null on the last. S3 cannot search, so `search` (any
case) narrows each page: a page may hold fewer than `size` files, or none, while `next` still leads
on. A listing has no `total`.

## Links

`parseS3Url(url)` reads a link a reader pastes: `s3://my-graphs/data/network.graphml`, a bucket
address (`https://my-graphs.s3.us-east-2.amazonaws.com/data/network.graphml`, also without the
Region) or a path-style address (`https://s3.us-east-2.amazonaws.com/my-graphs/data/network.graphml`).
It returns `{ bucket, region, key }` to load or list with. Anything else is rejected with
`E_SOURCE_PARAM` (`name: "url"`).

## Errors

| Code                 | When                                                                        |
| -------------------- | --------------------------------------------------------------------------- |
| `E_SOURCE_NOT_FOUND` | no such bucket or file                                                      |
| `E_SOURCE_FORBIDDEN` | the bucket or file is not public, or the credentials may not read it        |
| `E_SOURCE_BLOCKED`   | in a browser, the bucket's CORS configuration does not allow the page       |
| `E_SOURCE_RESPONSE`  | the file is in no format graph-io reads, or a listing answer is not S3's    |
| `E_SOURCE_PARAM`     | `bucket` or `region` is not a valid name, or `key` holds a `.` or `..` part |
