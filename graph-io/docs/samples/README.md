# Sample files

The graph files the graph-io guide uses in its examples. They are the Game of Thrones character
network from [sample-social-network-datasets](https://github.com/melaniewalsh/sample-social-network-datasets)
by Melanie Walsh, released under CC0 (public domain).

- `got-network.graphml`: 107 characters (with labels) and the weighted edges between them.
- `got-edges.csv`: the same edges as a CSV edge table (`Source,Target,Weight`).
- `got-nodes.csv`: the characters as a CSV node table.
