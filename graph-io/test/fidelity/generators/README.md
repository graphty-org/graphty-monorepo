# Style fidelity generators

The seeded scripts that wrote the generated files of the style fidelity corpus (`../corpus-samples.ts`). Each writes
the same bytes for the same seed; the committed files and their reference scenes were made with them.

| Script                     | Writes                                                                                                                                                                                                                                                                                                                                                                              |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `build-synthetic.mjs`      | `syn-mappings` and `syn-bypass` in a running Cytoscape 3.10.5 over CyREST, saved by Cytoscape as XGMML, CX, CX2 and a session                                                                                                                                                                                                                                                       |
| `gen_gexf.py`              | `gexf/fidelity/synth-nx-viz.gexf`, `gexf/fidelity/synth-13-hierarchy.gexf` (needs networkx)                                                                                                                                                                                                                                                                                         |
| `gen_pajek.py`             | `pajek/fidelity/synth-vertices.net`, `pajek/fidelity/synth-lines.net`                                                                                                                                                                                                                                                                                                               |
| `gen-synthetic.py`         | `graphml/fidelity/synthetic-nodes.graphml`, `graphml/fidelity/synthetic-edges.graphml`, `gml/fidelity/synthetic-coverage.gml` (needs networkx)                                                                                                                                                                                                                                      |
| `dot_make_synthetic.py`    | `dot/fidelity/synth-nodes.gv`, `dot/fidelity/synth-edges-clusters.gv`                                                                                                                                                                                                                                                                                                               |
| `json_gen_synthetic.py`    | the `json/fidelity/*synth*.json` files                                                                                                                                                                                                                                                                                                                                              |
| `gen_repros.py`            | the `repro-*` files: small reproductions of defects found in corpus files whose licenses do not allow committing them                                                                                                                                                                                                                                                               |
| `specimens/gexf-gephi.mjs` | the GEXF specimen sheets `../specimens/gexf/*.gexf` and their pages `../specimens/gexf/pages.json` (each sheet under one Gephi Preview setting), and `specimens/gexf-gephi-vocabulary.json`, the vocabulary they cover, read from the GEXF 1.3 schema and Gephi's own Preview property list (`specimens/gexf-gephi-preview-properties.json`, written by `GephiExport.java --props`) |

The specimen sheets (`../specimens/README.md`) are placed by one shared layout, `sheet-layout.json` (canvas, corner
anchors, the grid, caption offsets and the neutral baseline), read by `sheet_layout.py` for Python generators and
`sheet-layout.mjs` for Node generators; each runs a self-check when run directly. Their generators go in
`specimens/`, one per format family.

| Specimen generator                 | Writes                                                                                                                                           |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `specimens/graphviz_vocabulary.py` | `specimens/graphviz-vocabulary.json`: Graphviz's attributes, shapes, arrows, styles, splines, compass points and color schemes from graphviz.org |
| `specimens/graphviz.py`            | `../specimens/dot/*.gv` and their images; fails when a vocabulary entry is on no sheet and not listed as drawing nothing                         |
