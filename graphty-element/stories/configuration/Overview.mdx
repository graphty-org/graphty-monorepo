# Configuration

How the element itself behaves, apart from the graph it draws: today, its log. The data, the
layout and the look of the graph each have a section of their own.

## The smallest example

The log is off until your page turns it on. One call shows every warning and error the element
makes, in the browser console:

```ts
import { GraphtyLogger, LogLevel } from "@graphty/graphty-element/logging";

await GraphtyLogger.configure({ enabled: true, level: LogLevel.WARN });
```
