# Examples

Whole pages built on the element: the graph plus the controls an application draws around it. Each
one says on its canvas what it needs to run.

## The smallest example

An application talks to the element through its properties and methods. This page sends a
command typed in plain language to the graph:

```ts
const graph = document.querySelector("graphty-element");

await graph.enableAiControl({ provider: "mock" }); // or "openai", "anthropic", "google", "webllm"
const result = await graph.aiCommand("switch to circular layout");
console.log(result.message);
```

## In this section

- [AI control](?path=/story/ai-control--default): typing or speaking a command such as "make
  database nodes blue". It needs an API key of your own, or a browser with WebGPU for a model that
  runs in the page, or the Mock provider, which needs nothing.
