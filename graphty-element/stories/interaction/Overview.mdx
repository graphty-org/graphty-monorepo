# Interaction

What a reader does with a graph once it is on screen: pick nodes, keep a selection under a name,
undo a change, and move or record the view. The element handles the mouse, touch and keyboard on
its own; everything below can also be done from code.

```js
const graph = document.querySelector("graphty-element");

graph.addEventListener("selection-changed", (event) => {
    console.log("selected", event.detail.currentNode?.id);
});

graph.selectNode("alpha"); // select from code
await graph.session.undo(); // take back the last change
await graph.resetCamera({ animate: true }); // fly back to the starting view
```
