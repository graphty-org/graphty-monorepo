# Styling

How every node and edge in a graph looks, and what the graph is drawn against.

An element's look is a **stack of style layers**. Each layer has a selector, which says which nodes
or edges it is about, and a set of channels, which says how they look: `node.color`,
`node.shape`, `edge.width`, `node.label` and so on. Layers paint bottom first, so a later layer
wins wherever two set the same channel on the same node. A channel's value can be written out, or
read from a column of your data so each node gets its own.

The smallest working example colors two kinds of node:

```html
<graphty-element style="display: block; width: 100%; height: 600px"></graphty-element>

<script type="module">
    import "@graphty/graphty-element";

    const graph = document.querySelector("graphty-element");
    graph.session.styles.add({
        name: "Servers are blue",
        target: "node",
        selector: { match: "expression", where: "data.type == 'server'" },
        set: { "node.color": "#3B82F6", "node.size": 2 },
    });
    graph.nodeData = [
        { id: "web", type: "server" },
        { id: "db", type: "server" },
        { id: "alice", type: "person" },
    ];
    graph.edgeData = [
        { src: "alice", dst: "web" },
        { src: "web", dst: "db" },
    ];
</script>
```
