# Components

Pieces the app is built from, shown on their own.

- [Graphty](?path=/docs/components-graphty--docs) -- the app's React wrapper around
  `<graphty-element>`, drawing a small ring of nodes.

The app's buttons, inputs and other controls are compact-mantine components, documented with every
size and state in [compact-mantine's own Storybook](https://graphty.app/storybook/compact-mantine/).
To see the components working together, open the [Workspace](?path=/docs/workspace-overview--docs).

Reference: the [graphty-element documentation](https://graphty.app/docs/graphty-element/), for the
element the Graphty component wraps.
