# Examples

- [Full app](?path=/docs/components-app--docs) -- the whole graphty app, running in this page. It
  opens on the start screen: pick a sample graph, such as Zachary's karate club, or open a file of
  your own, then analyze, style and export it.

Every region of the app is also shown on its own, state by state, in the
[Workspace](?path=/docs/workspace-overview--docs) section.

Reference: [graphty.app](https://graphty.app/) runs the same app, and the
[graphty-element documentation](https://graphty.app/docs/graphty-element/) covers the element that
draws the graph.
