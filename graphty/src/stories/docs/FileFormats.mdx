# File formats

graphty opens a file from the start screen (**Open project or file...**, Ctrl+O or Cmd+O), from
**New from data...**, or when you drop it anywhere in the window. A file can also come from a web
address: on the [Data page](?path=/docs/workspace-data-page--docs), under Tables, choose **+** and
then **From a URL...**.

The app tells the format from the file itself. When it cannot, the Data page says so and File
settings lets you pick it ([a file it cannot tell](?path=/story/workspace-data-page--detect-none)).

## Tables of your own

A spreadsheet works too. Save it as CSV: an edge list needs one row per edge, with a column for
where it starts and a column for where it ends; a node table, if you have one, needs one row per
node with an id column. Add both on the Data page and it matches them before loading, as in
[a node table and an edge table](?path=/story/workspace-data-page--transfers).

Reference: [every format in detail](https://graphty.app/docs/graph-io/guide/formats/), in the
graph-io documentation.
