# Step-by-step simulations

`forceAtlas2` and `fruchtermanReingold` run to the end and return the final drawing. Their simulations run one
iteration at a time instead, so you can draw every frame, let a reader drag or pin nodes while the forces keep
running, and stop as soon as the drawing has settled.

```ts
import { createSimulation } from "@graphty/layout";

const positions = new Float32Array(3 * graph.nodeCount).fill(NaN); // x, y, z per node; NaN rows are seeded
const sim = createSimulation("forceatlas2", { maxIter: 300, seed: 42 });
sim.load(graph, positions);
while (!sim.settled) {
    sim.step(); // writes the new coordinates into positions
}
sim.dispose();
```

The simulation never returns positions: it writes them into the array you pass to `load()`, so your renderer reads
them with no copy. `setPosition(index, x, y, z)` moves one node (a drag) and `setFixed(mask)` pins nodes.
